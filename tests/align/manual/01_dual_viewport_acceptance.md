# 듀얼 뷰포트·Data Layers·마커 드래프트 인수 검사

## 목적

Blender 5.2에서 현재 창의 듀얼 뷰포트, A/P 공용 레이어 선택, 양방향 그룹 이동, 독립 표시 토글과 마커 입력 보호를 확인합니다. 실제 정합 계산은 실행하지 않으며 Scene Object·Collection·Proxy를 만들지 않습니다.

## 사전 조건

- Blender 5.2의 새 일반 파일을 엽니다.
- `Edit > Preferences > Add-ons`에서 `COLMAP Align`을 활성화합니다.
- Blender 상단 `Window > COLMAP Align 열기`로 진입합니다.

## 검사 절차

1. 별도 OS 창 없이 현재 Blender 창이 왼쪽·오른쪽 `VIEW_3D`로 전환되는지 확인합니다.
2. 오른쪽 N Sidebar에만 `COLMAP Align` 탭이 표시되고, 수동 종료 버튼이 노출되지 않는지 확인합니다.
3. `Data Layers`에는 `Demo_1`부터 `Demo_4`까지 순서대로 표시되어야 합니다.
4. `Demo_1`, `Demo_2`는 밝은 A 그룹과 Anchor 아이콘, `Demo_3`, `Demo_4`는 어두운 P 그룹으로 표시되어야 합니다.
5. 네 행 모두 오른쪽 끝에 독립 표시 토글이 있어야 합니다.
6. 초기 왼쪽 뷰에는 표시 ON인 `Demo_1`, `Demo_2`가 보이고 오른쪽 뷰는 비어 있어야 합니다.
7. `Demo_3`을 한 번 클릭합니다. 행 전체가 회색 박스로 선택되고 오른쪽 뷰에 `Demo_3`만 표시되어야 합니다.
8. `Demo_2`를 한 번 클릭합니다. A 그룹 행에도 같은 회색 선택 박스가 이동해야 하며 오른쪽 뷰는 비어 있어야 합니다.
9. `Demo_3`을 같은 행에서 빠르게 두 번 클릭합니다. 밝은 A 그룹과 Anchor 아이콘으로 바뀌고 왼쪽 뷰에 추가되어야 합니다.
10. 선택된 `Demo_3`을 다시 빠르게 두 번 클릭합니다. 어두운 P 그룹으로 바뀌고 왼쪽에서 제거되어 오른쪽 뷰에 표시되어야 합니다.
11. `Ctrl+Z`와 `Ctrl+Shift+Z` 또는 `Ctrl+Y`로 직전 A↔P 이동이 한 건씩 복원되는지 확인합니다.
12. 내부 기준 Anchor가 있는 A 레이어를 P로 옮기면 남은 가장 이른 A가 Anchor를 승계하는지 확인합니다. 마지막 A 하나는 P로 이동할 수 없어야 합니다.
13. 각 레이어의 표시 토글을 차례로 끕니다. 다른 레이어의 표시·선택·그룹은 변하지 않아야 합니다.
14. 선택 P 레이어를 숨기면 오른쪽 점군과 마커 추가가 비활성화되고, 다시 표시하면 복구되어야 합니다.
15. A 레이어를 숨기면 해당 레이어만 왼쪽 뷰에서 사라지고 다른 A 레이어는 유지되어야 합니다.
16. P 레이어를 선택하고 마커 드래프트를 연 뒤 다른 레이어 선택과 A/P 그룹 이동이 거부되는지 확인합니다.
17. 다른 작업공간으로 이동하면 Align 세션이 자동 종료되고 Blender 기본 Undo가 유지되는지 확인합니다.
18. 진입·사용·종료 전후에 신규 Scene Object·Collection·Proxy가 생기지 않았는지 확인합니다.
19. 각 A/P 뷰포트 왼쪽 위 역할 라벨 옆에 Home 아이콘 Frame All 버튼이 표시되는지 확인합니다. 표시 대상이 없는 P 뷰에서는 버튼이 숨겨져야 합니다.
20. A 뷰에서 버튼 또는 마우스를 A `WINDOW` Region에 둔 `Home`을 실행합니다. 보이는 A 그룹 전체만 맞춰지고 P의 위치·거리·회전·투영 모드는 변하지 않아야 합니다.
21. P 레이어를 둘 이상 선택한 뒤 P 뷰에서 버튼, `Home`, `View` 메뉴의 `P 그룹 전체 보기`를 차례로 실행합니다. 보이는 선택 P 전체가 하나의 경계로 맞춰지고 숨김·비선택 P와 A 고스트는 제외되어야 합니다.
22. A/P 각각의 `View` 메뉴 맨 위에서 `A 그룹 전체 보기` 또는 `P 그룹 전체 보기`가 보이는지 확인합니다. 일반 작업공간, N 패널, 헤더, 파일 브라우저의 메뉴·`Home`에는 전용 동작이 나타나면 안 됩니다.
23. 일반 Workspace로 이동한 뒤 기존 READY Align Workspace 탭을 다시 선택합니다. N 패널은 사라지지 않고 세션 재연결 중에만 잠시 비활성화된 뒤 다시 조작 가능해야 합니다.

## 합격 기준

- 모든 A/P 레이어는 동일한 공용 선택 배경을 사용할 수 있습니다.
- 같은 행의 두 클릭이 Blender 사용자 설정의 더블클릭 시간 안이면 A↔P 이동 한 건으로 처리됩니다.
- P→A와 A→P 모두 선택 ID를 유지하며 세션 Undo/Redo 한 건으로 기록됩니다.
- 표시 토글은 레이어별로 독립적이며 그룹 Undo/Redo가 이후 표시 변경을 덮어쓰지 않습니다.
- 왼쪽은 표시 ON A 전체, 오른쪽은 표시 ON 선택 P 하나만 렌더합니다.
- 실제 Sim(3)·ICP·품질 평가·정합 승인은 실행되지 않습니다.
- COLMAP 점군과 OBJ 메시를 섞어 표시한 경우에도 현재 표시 축·확정/미리보기 transform이 적용된 소유 레이어 경계만 화면에 들어와야 합니다.
- Frame All은 RegionView3D의 회전·원근/직교 모드를 유지하고 위치·거리만 바꾸며, Scene Object·Collection·사용자 키맵을 변경하지 않아야 합니다.

## 자동 테스트 경계

Blender `event_simulate`는 `DOUBLE_CLICK` 값을 직접 만들지 못합니다. 자동 GUI 회귀는 실제 N 패널 행에 `PRESS/RELEASE`를 두 번 보내며, 애드온이 `PreferencesInput.mouse_double_click_time`을 기준으로 P→A와 A→P를 판정하는 전체 경로를 검증합니다.
