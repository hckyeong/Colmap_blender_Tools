# Align 유휴 내보내기 파일 로드 오류 수정 0.3.38

- 작성일: 2026-09-07

## 원인

`.blend` 파일을 열기 전 세션 정리가 COLMAP 내보내기 정리 함수를 호출합니다. 이 함수는 실행 중인 작업이 없어도 정리 사유를 `last_error`에 저장했고, 패널은 이 값을 실제 내보내기 오류로 표시했습니다. 따라서 한 번도 내보내지 않은 파일에서도 `새 Blender 파일을 불러와 구조 통합 작업을 정리했습니다.`가 오류 원인으로 나타났습니다.

## 수정

- 내보내기 작업이 없으면 오류를 포함한 이전 상태를 비우고 유휴 상태로 돌아갑니다.
- 실제 작업이 있으면 기존 순서대로 작업·후보 출력을 정리하고 타이머를 해제한 뒤 중단 사유를 남깁니다.
- 내보내기 실행 실패의 오류 표시와 출력 확정·취소 정책은 유지합니다.
- 새 회귀 검사를 정식 Align 소스 검사 목록에 추가합니다.

## 검증 범위

`tests/align/blender/test_merge_export_runtime.py`에서 작업 없는 상태의 정리, 작업 중단과 타이머 해제, 파일 교체, 기존 실패 진단을 확인합니다. 수정 전 유휴 상태에서 사용자와 동일한 오류 문구가 남는 것을 재현했습니다.

## 검증 결과

- Blender 5.2 내보내기 상태 검사 9개 통과. 작업 없는 정리 검사는 유휴·사전 검사 완료·완료·실패·취소의 5개 상태를 포함합니다.
- 정식 빌드의 구조 12개·공존 11개·Modifier 코어 216개·Projection 코어 40개 검사와 통합 등록·해제, CC 스테이징 실제 정렬, ZIP 검증 통과.
- 정식 `user_default` 설치본 0.3.38에서 임시 `.blend`를 저장하고 실제 파일 열기 처리로 다시 열었습니다. 내보내기 실행 없이 `IDLE`, 빈 오류 문구, 빈 작업 참조를 확인했습니다.
- 설치 전후 사용자 `userpref.blend`의 SHA-256이 같았습니다. 사용자 작업 파일은 열거나 저장하지 않았습니다.

배포 ZIP은 `build/colmap_tools-0.3.38.zip`이며 SHA-256은 `f52314b234a6922e67042466a27d028eaf014dfdfa430182d5c62c6335d0d69b`입니다. 설치본 확인 결과는 `build/align-export-idle-0.3.38-installed.json`에 보관합니다.

설치된 Blender 프로세스는 메모리에 이전 코드를 유지하므로 수정본 설치 후 Blender를 재시작해야 적용됩니다.
