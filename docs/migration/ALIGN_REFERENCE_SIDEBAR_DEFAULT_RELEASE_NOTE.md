# Align 왼쪽 N 패널 기본 닫힘 0.3.40

- 작성일: 2026-09-07

## 변경

새 Align 작업공간의 왼쪽 A 뷰는 N 패널을 닫고 시작합니다. 오른쪽 P 뷰는 기존 정렬 패널을 열며 0.3.39의 기본 폭을 유지합니다.

0.3.39 Seed는 패널이 열린 상태였고 A/P 화면을 분할할 때 양쪽에 그 상태가 복제되었습니다. Seed 생성기에서 폭을 설정한 뒤 Align Seed의 패널 표시만 닫아 저장합니다. 기존 세션 구성은 오른쪽 P 뷰의 패널만 열므로 새 작업공간의 왼쪽에는 닫힌 상태가 유지됩니다.

기존 작업공간의 표시 상태를 바꾸는 코드는 추가하지 않습니다. 사용자가 왼쪽 패널을 직접 열거나 기존 `.blend`에 열린 상태로 저장한 경우 그대로 유지합니다. Seed 생성 명령과 폭 설정은 [0.3.39 변경 기록](ALIGN_SIDEBAR_DEFAULT_WIDTH_RELEASE_NOTE.md)을 따릅니다.

## 검증 결과

- Seed 중립 데이터·메타데이터 검사 통과.
- 소스와 정식 설치본의 실제 GUI에서 첫 진입의 왼쪽 패널 닫힘, 오른쪽 패널 열림·477픽셀 폭 확인.
- 왼쪽 패널을 수동으로 연 뒤 일반 작업공간을 왕복해도 열린 상태 유지 확인.
- 정식 빌드 검사 279개와 통합 등록·해제, CC 스테이징 실제 정렬, ZIP 검증 통과.
- 정식 설치본 0.3.40 적용. 설치 전후 사용자 환경설정 파일의 SHA-256 일치.
