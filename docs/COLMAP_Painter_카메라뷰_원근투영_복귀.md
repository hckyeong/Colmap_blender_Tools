# Painter 카메라뷰 원근투영 복귀

- 작성일: 2026-10-06.
- 범위: Painter의 카메라뷰 진입·이탈. Align·Modifier·일반 Blender 뷰포트의 탐색 설정은 변경하지 않는다.

## 원인과 변경

카메라뷰 진입은 `RegionView3D.view_perspective`를 직접 `CAMERA`로 지정하고 있었다. 이 속성은 현재 투영 상태만 변경하며 Blender가 카메라 이탈 시 복구할 이전 투영 상태는 갱신하지 않는다. 실제 화면에서 정사투영→Look Through Camera→기본 카메라 토글 이탈이 정사투영으로 돌아가는 것을 재현했다.

카메라뷰에 들어갈 때 원근투영을 설정한 뒤 Blender의 정식 `view3d.view_camera` 오퍼레이터로 진입한다. 이 과정에서 Blender가 원근투영과 현재 탐색 상태를 복귀 대상으로 기록한다. Look Through Camera, 관리 프레임 전환, 스텐실 재연결의 진입 경로가 같은 함수를 사용한다. 이미 카메라뷰인 경우에는 다시 토글하거나 화면 위치·확대 상태를 변경하지 않는다.

자유 뷰의 회전·위치·거리와 카메라 프레임 확대·이동 상태는 보존한다. 사용자가 자유 뷰에서 직접 정사투영을 선택하는 기능도 유지한다. 전역 환경설정 변경이나 반복 타이머로 정사투영을 강제 해제하지 않는다. 전환이 실패하면 원래 현재 투영 상태로 복구하고 오류를 전달한다.

공식 구현에서 카메라 진입은 `ED_view3d_lastview_store`를 호출하고 이탈은 저장된 `lpersp`를 사용한다. 근거: [Blender 카메라뷰 오퍼레이터](https://github.com/blender/blender/blob/main/source/blender/editors/space_view3d/view3d_navigate_view_camera.cc), [투영 속성 정의](https://github.com/blender/blender/blob/main/source/blender/makesrna/intern/rna_space.cc).

## 검증 기준

1. 정사투영에서 카메라뷰 진입 후 기본 카메라 토글로 이탈하면 원근투영이다.
2. 세 진입 경로와 반복 진입에서 탐색 상태·현재 카메라·배경 연결을 유지한다.
3. 페인트 종료·재진입, 기존 이미지·레이어와 배경 표시 검사를 통과한다.
4. 현재 Blender에 수정본을 설치하고 실제 카메라 이탈을 확인한다. 프로젝트를 저장하거나 레이어를 초기화하지 않는다.
5. 최상위 `colmap_tools.zip`을 갱신한다.
