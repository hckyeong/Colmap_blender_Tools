# 최상위 설치 ZIP 배포

- 요청: GitHub에서 쉽게 내려받도록 최신 설치 ZIP을 저장소 최상위에 보관하고, 이후 빌드도 같은 위치에 생성하며 이전 설치 ZIP을 정리한다.
- 정식 파일: `colmap_tools.zip`. 실제 제품 버전은 내부 `blender_manifest.toml`에서 관리한다. Git에서는 이 ZIP만 예외적으로 추적한다.
- 빌드: 기존 소스·등록·정렬·ZIP 검증 후 최종 파일을 교체한다. 검증 실패 시 기존 최종 ZIP을 보존한다. 교체 성공 후 같은 출력 폴더에서 버전 이름이 붙은 정식 설치 ZIP만 정리한다.
- 명시적 출력 경로 지정은 유지한다. SmallGicp·Full 비교 빌드는 각각 별도 이름을 사용해 정식 파일을 덮어쓰지 않는다.
- 설치 검사와 설치본 벤치마크의 기본 ZIP 경로를 최상위로 맞춘다. README와 설치 매뉴얼에 고정 다운로드 링크를 제공한다.
- 일회성 정리: 저장소 안에서 설치 패키지임이 확인된 통합판 및 통합 전 도구의 버전별 ZIP을 삭제한다. 네이티브 재빌드 원문·Python 표준 라이브러리·개발 의존성 압축 파일은 설치 패키지가 아니므로 유지한다. Git 이력은 다시 쓰지 않는다.
- 검증: 이전 설치본만 삭제하는 경계 검사, 정식 빌드, 격리 설치, ZIP 내부 버전과 Git 업로드 파일 일치, 원격 main 커밋 확인.
