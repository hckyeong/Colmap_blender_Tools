# 이 세션의 데스크톱 작업 규칙

기록일: 2026-10-21. 적용 범위는 현재 대화 세션이다.

- GUI 작업과 블렌더 실행·테스트는 Windows 가상 **데스크톱 2**에서 수행한다.
- **데스크톱 2가 없을 때만 데스크톱 1**에서 수행한다.
- GUI 작업 전에 가상 데스크톱 목록과 현재 데스크톱을 확인한다. 데스크톱 2가 있는데 현재 화면이 데스크톱 1이라는 이유로 데스크톱 1에서 작업하지 않는다.
- 블렌더 창도 위 규칙으로 선택한 데스크톱에서 연다. 테스트 창은 다른 작업 창 뒤에 배치한다.
- 사용자가 데스크톱 1에서 작업하는 동안 화면 전환이나 창 활성화로 방해하지 않는다. 데스크톱 2의 기존 블렌더에 MCP로 명령을 전달하는 방식을 우선 사용한다.
- 기존 블렌더에서 검증할 때는 해당 창이 데스크톱 2에 있는지 확인하고, 검증으로 변경한 시점·피벗·선택 상태를 복원한다.
- 데스크톱 2에 블렌더가 없으면 새 창을 활성화하지 않고 해당 창만 데스크톱 2로 옮긴 뒤 작업한다. 사용자에게 화면 전환을 필수 단계로 요구하지 않는다.
- 숨김 실행 옵션만으로 창 소속이나 비활성 상태가 보장된다고 판단하지 않는다. 가상 데스크톱 소속과 전경 창을 실제로 확인한다. 실행 예시는 `build/verification/pivot-install-20261021/desktop2_import.py`에 있다.
