# Align 점–평면 정렬과 노말 비교 적용 계획

작성일: 2026-09-20. 이 문서는 구현 전 결정과 완료 후 측정 결과를 구분한다.

## 1. 목적과 현재 동작

현재 0.3.66은 정확 삼각면 BVH와 전처리 재사용을 적용했지만, 변환 계산은 CCCoreLib의 점–점 최소제곱이다. 메시 최근접 검색은 이미 대응점과 원본 삼각형 번호를 함께 반환한다. 이를 재사용하여 점–평면 변환을 계산하고, 메시에서 추출한 등록 표본에는 출처 면의 노말을 붙여 부적절한 대응을 걸러낸다.

기존 MeshLib 비교 실험의 ICP 계산 합계는 점–점 3.246199초, 점–평면 1.055935초였다. 다른 엔진에서 관찰한 가능성일 뿐 제품의 예상 시간으로 간주하지 않는다. 이번에는 제품 C++ 구현과 실제 `C:/Users/gksru/Desktop/Untitled.blend`의 전체 Align을 측정한다.

## 2. 적용 범위와 보존 조건

| 형상 조합 | 변환 계산 | 양쪽 노말 비교 |
|---|---|---|
| 메시 → 메시 | 강체는 기존 점–점, 배율 보정은 점–평면 | 배율 보정에서 등록 표본 출처 면과 대응 기준 면 비교 |
| 점군 → 메시 | 강체는 기존 점–점, 배율 보정은 점–평면 | 이동 점군 노말 추정을 추가하지 않으므로 생략 |
| 메시 → 점군 | 기존 역등록 방향에서 강체 점–점 후 배율 보정 점–평면, 최종 역변환 | 등록 점군의 노말이 없으므로 생략 |
| 점군 → 점군 | 기존 점–점 | 기존 동작 |

- 5만 등록 표본, 독립 평가 표본·시드·좌표·출처·순서와 후보 반경을 보존한다.
- 강체 후 배율 보정의 두 단계, 누적 추가 배율 ±10%, 원본 메시 전체와 정확 BVH 검색을 유지한다.
- 최종 후보 선택과 양방향 유클리드 표면 거리 품질 판정은 변경하지 않는다. 점–평면 잔차를 기존 품질 거리로 대신하지 않는다.
- 점–평면 경로에서도 기존 먼 점·부분 겹침 필터, 취소, 진행, 수명·메모리 보호와 실패 전달을 보존한다.
- 원본 OBJ·프로젝트·사용자 설정을 수정하거나 저장하지 않는다. Modifier·Painting·뷰포트 작업과 기존 미커밋 변경은 대상이 아니다.
- 새 정렬 엔진·외부 수학 라이브러리를 설치하거나 MeshLib 코드를 가져오지 않는다. 제품 구현과 기존 CCCoreLib 수학 API를 사용한다.

## 3. 노말 전달과 대응 필터

### 실제 회귀에 따른 적용 범위 확정

두 단계 모두 점–평면을 적용한 후보는 기존 10% 부분 겹침 정답 회귀를 통과하지 못했다. 배율 오차를 회전·이동만으로 줄이는 강체 단계가 좁은 곡면에 과도하게 맞춰지고, 기존 고정 겹침 평가에서 올바른 배율 보정 후보보다 그 강체 후보의 RMS가 낮게 나왔다. 최종 품질·후보 선택 기준을 바꾸지 않기 위해 제품은 **기존 강체 점–점 + 배율 보정 점–평면**으로 확정한다. 같은 입력의 단계별 비교에서 이 조합만 정답 위치·배율·회전과 제품 품질을 함께 통과했다. 노말 비교도 점–평면 배율 보정에 적용한다. 네이티브의 6/7변수 점–평면 API와 개별 수치 검사는 보존한다.

비교 하네스는 전면 점–평면을 명시적 실험 모드로 구분하고, 최종 제품 벤치마크는 점–점 기준선·배율 점–평면·배율 점–평면+노말의 세 조합을 사용한다. 이 범위 변경으로 얻은 실제 시간 절감만 보고하며 전면 적용의 속도를 제품 성능으로 제시하지 않는다.

메시 표본의 `source_indices`로 선택된 삼각면 5만 개만 조회하여 단위 면 노말을 계산한다. 전체 메시 노말 배열이나 추가 BVH를 만들지 않는다. 등록 좌표와 같은 순서로 배정도 노말 파일을 기록하고, 두 번째 등록에는 강체 회전만 적용한다. 순수 이동과 양의 균일 배율은 노말 방향을 바꾸지 않는다.

네이티브 지오메트리 설명에 선택적 `normals_file`을 추가한다. 정확한 파일 길이·유한성·영벡터·단위 길이·경로 충돌·캐시 설명 동일성을 검증한다. 노말 메모리도 기존 형상 상주량에 포함한다. 메시 모델의 노말 파일은 필요 없으며 대응 삼각면 세 정점의 외적으로 즉시 얻는다.

초기 정책은 `abs(dot(n_data, n_model)) >= cos(60°)`인 무방향 비교다. OBJ 면 방향이 뒤집혀 있어도 같은 기울기의 면을 배제하지 않는다. 따라서 앞면·뒷면 구별을 보장하는 필터로 설명하지 않는다. 서로 크게 교차하는 표면 방향의 대응을 배제하는 목적이다. 단위 노말의 내적은 반올림 범위를 제한하고, 동일한 대응 선택을 RMS와 변환 계산에 적용한다. 대응이 부족하면 명확한 오류를 반환하며 기준을 자동 완화하지 않는다.

거리 조회와 독립 평가는 이 필터를 사용하지 않는다. 필터 비용과 배제 수는 별도로 기록하고, 실제 벤치마크에서 점–평면 단독과 함께 비교한다.

## 4. C++ 변환 계산

기존 `Register` 공개 진입점과 `Parameters`의 기본 의미를 보존하고, 기존 메시 등록 문맥에 명시적 점–평면 선택과 노말 임계값을 추가하는 후행 패치를 작성한다. 기존 패치 파일과 중간 해시는 변경하지 않는다.

현재 이동점 p, 대응점 q, 기준 단위 노말 n에 대해 `n·(p-q)`의 제곱합을 최소화한다. 중심화한 좌표를 사용하고, 강체는 회전 3·이동 3의 6변수, 배율 단계는 균일 배율을 더한 7변수를 푼다. 작은 선형계에는 기존 배정도 SVD를 사용한다. 미소 회전은 적절한 회전 행렬로 변환하며 양의 균일 배율만 허용한다.

배율 경계에 닿으면 제한한 배율을 고정하고 나머지 변수를 다시 계산한다. 기존 점–점 중심 이동식으로 점–평면 결과의 이동을 덮어쓰지 않는다. 유한성·누적 배율·행렬 검증을 유지한다.

평면 등 관측 불가능한 방향은 SVD의 수치 순위로 판별하고 최소 노름 해에서 해당 성분을 0으로 둔다. 이는 명시한 점–평면 목적함수의 해이며 다른 엔진으로의 자동 재시도가 아니다. 유효 방정식이나 관측 가능한 성분 자체가 부족한 입력은 오류다. 순위와 종료 원인을 진단에 기록하며 실제 기하학적 정확도는 독립 거리 평가로 판단한다.

먼 점·부분 겹침 필터는 유지한다. 최초 구현은 기존 유클리드 RMS 수락 판정을 유지했지만, 10% 부분 겹침 회귀에서 배율 첫 해가 거절되어 배율 1을 반환했다. 같은 입력에서 기존 점–점은 통과하고 점–평면은 노말 필터 유무와 관계없이 실패했다. 점–평면 풀이와 유클리드 수락 기준이 서로 다르고 필터 재선택 때 유효 대응 집합도 바뀌므로, 내부 수락 정책을 아래와 같이 일치시킨다. 노말 배제 0개·선형 순위 6/7인 이 사례의 실제 결과는 후속 회귀로 검증한다.

점–평면은 현재 대응점·면 노말·가중치를 고정한 실제 점–평면 제곱오차 감소로 증분을 수락한다. Rodrigues 변환과 배율을 실제 적용한 오차를 검사하고 증가하면 회전·중심 기준 이동·배율 증분을 함께 절반으로 줄여 선 탐색한다. 양의 배율과 기존 누적 배율 경계는 유지한다. 대응 재선택 뒤 서로 다른 점 집합의 유클리드 RMS를 이유로 이미 검증한 증분을 거절하지 않는다. 제품이 사용하는 반복 상한 모드에서는 기존 상한 또는 표현 가능한 감소가 없는 시점에 종료한다. 별도 오차 수렴 모드를 명시했을 때만 그 모드의 감소량 임계값을 사용하며, 기존에 비활성이던 기본값 `1e-5`를 제품에 새로 적용하지 않는다. 외부 `final_rms`, 독립 평가, 후보 선택과 품질 기준은 계속 유클리드 거리다. 기존 점–점 경로의 수락 정책은 변경하지 않는다.

관측 불가능한 방향은 계속 최소노름 해로 유지한다. 선 탐색이 수치적으로 유효한 감소를 만들지 못하면 직전 변환으로 수렴 종료하며, 다른 계산법으로 전환하거나 품질 허용오차를 완화하지 않는다.

단정도 좌표 반올림만 줄이며 반복하는 현상은 실제 최대 점 이동량으로 차단한다. 유효 입력의 좌표 절댓값 최댓값과 중심 반경 중 큰 값에 `epsilon(float32)`를 곱한 한계 이하의 실제 점 이동이면 직전 변환으로 수렴한다. 이는 좌표 범위 기반 표현 정밀도이며 성분별 정확한 1 ULP와는 다르다. 작은 목적함수 감소만으로 종료하지 않으므로 약한 곡면에서 여전히 큰 회전·이동이 필요한 해를 조기 중단하지 않는다.

## 5. 실행·저장·배포 계약

네이티브 실행 규약은 `cccore-native-v8`, 알고리즘 식별자는 `cccore-icp-v7`로 갱신한다. 현재 실행은 맞는 바이너리·DLL·Manifest만 허용하고 과거 확정 결과 복원은 보존한다. 기존 작업 입력 형식은 필요한 경우를 제외하고 유지한다.

등록 방법, 노말 필터 적용 여부·배제 수, 점–평면 풀이 횟수·최소 수치 순위를 기존 내부 구간 시간과 구분하여 기록한다. `final_rms`와 거리 명령은 유클리드 거리 의미를 유지한다. 제품에서 반복별 디버그 로그는 작성하지 않는다.

새 코어 패치·원문 해시·빌드 스크립트·재빌드 원문 ZIP·검증 도구를 함께 갱신한다. 기존 실행 파일은 벤치마크 기준선으로 보존한다. 검증한 새 배포 ZIP을 만들고, 실제 설치 여부와 원격 푸시 여부는 완료 보고에서 분명히 구분한다.

## 6. 분담

- 감독 에이전트: 문서와 현행 계약 검토, 계획 작성, 작업 경계 조정, 빌드·배포 계약, 실제 Blender 실행과 결과 판정.
- C++ 담당: 별도 후행 코어 패치의 점–평면 풀이·노말 대응 처리와 수치 진단. 기존 코어 진입점 보존.
- 연결 담당: 노말 표본 생성·네이티브 전달·메모리/경로 검증·실행/복원 계약과 네이티브 워커 연결.
- 검증 담당: 알려진 정답·부분 겹침·반전 노말·평면·배율 경계·취소 회귀와 재현 가능한 비교 도구.

서브에이전트는 받은 구체적 범위만 수행하며 계획서 열람이나 추가 재위임을 맡지 않는다. 부하가 큰 빌드·실데이터 측정은 감독자가 순차 수행한다.

## 7. 검증과 벤치마크

1. 기존 0.3.66 배포본·실행 파일·입력 지문을 보존하고 현재 프로젝트의 실제 Align 기준선을 다시 측정한다.
2. 작은 비대칭 메시의 알려진 강체·배율 변환, 평면의 관측 가능한 이동, 동일 형상, 노말 반전과 잘못된 노말 입력, 불충분한 대응을 검증한다. 기존 네 형상 조합·부분 겹침·취소·저장 복원 검사를 수행한다.
3. 같은 실제 5만 표본에서 점–점, 점–평면, 점–평면+노말 필터를 비교하여 각 효과를 구분한다. 예열과 본 측정을 분리하고 본 측정은 각 3회 순차 실행한다. 가능하면 순서를 교차하여 캐시·부하 편향을 줄인다.
4. 실제 `Untitled.blend`에서 보존한 동일 세 마커로 제품 Align 연산자를 실행한다. 전체 Align은 클릭 후 입력 준비부터 결과 반환까지이며 프로젝트 로드·복원·마커 준비는 별도로 기록한다.
5. 전처리·강체·배율·독립 평가 시간, 반복 횟수, BVH 생성·재사용, 메모리, 최종 품질과 실제 거리 지표를 비교한다. 변환 차이도 기록한다. 목적함수 변경이므로 행렬 동일성만으로 품질을 판정하지 않는다.
6. 기존 품질 기준·알려진 정답 회귀를 유지한다. 실데이터 독립 겹침 RMS는 기준선 대비 `max(1%, 정규화 2e-7)`보다 나빠지지 않아야 하고, 양방향 꼬리·공간 분포의 제품 판정도 통과해야 한다. 이 비교 한도는 제품 품질 기준을 변경하지 않는다.
7. 정확도 검증과 실제 시간 개선이 확인된 조합을 기본 경로로 채택한다. 실패·속도 역전은 그대로 보고하고 채택을 위해 기준을 사후 완화하지 않는다.

## 구현·검증 결과

### 채택한 구현

0.3.67은 **강체 점–점 → 배율 보정 점–평면**을 사용한다. 메시끼리의 배율 보정에는 무방향 60도 노말 필터를 적용한다. 네이티브 6/7변수 점–평면 계산 자체는 모두 구현했지만, 두 단계 전면 적용은 10% 부분 겹침에서 최종 후보의 정답 오차가 커져 제품에 채택하지 않았다. 최종 후보 선택·품질 허용치·표본 수를 바꾸지 않았다.

점–평면 수락은 고정 대응의 실제 변환 후 잔차 감소를 확인하며 좌표 표현 정밀도 이하의 이동에서 수렴한다. 노말은 기존 5만 등록 표본의 출처 면에서만 얻는다. 전체 메시 노말·추가 BVH·외부 엔진을 추가하지 않는다.

### 실제 Blender 프로젝트 비교

Blender가 내보낸 동일 형상·초기 행렬을 사용하여 각 조합을 1회 예열한 뒤 순서를 교차하며 3회씩 측정했다. 각 실행은 독립 세션이고 BVH를 새로 만들므로 다른 실행의 세션 캐시를 가져오지 않는다. 아래 솔버 시간에는 Blender 입력 추출과 화면 갱신이 포함되지 않는다.

### 정확도·메모리·회귀

- 실제 프로젝트의 독립 겹침 정규화 RMS: `5.1608453e-8 → 6.4547538e-9`. 두 버전 모두 기존 품질 검사 통과. 행렬 원소 차이 최댓값은 `1.2334246e-7`이며 목적함수 변경에 따른 차이로 기록했다.
- BVH: 양쪽 모두 2회 생성, 26회 재사용. 네이티브 최고 작업 집합은 `1,154,658,304 → 1,154,588,672`바이트로 사실상 같았다.
- 원본 `.blend`·OBJ의 실행 전후 상태가 같으며 저장하지 않았다. 실제 GUI와 반복 시험의 형상·마커·표본 동일성을 자동 대조했다.
- 네이티브 기존 51개와 신규 10개 통과. Python 솔버 58개·계약 20개·점–평면 입력 3개 및 표면 15개·전처리 10개·겹침 15개 통과. Blender 런타임 8개와 기존 승인 출처 v1~v6 복원 검증 통과.
- 제품의 기존 100%·70%·40%·20%·10% 부분 겹침 정답 회귀 5개 모두 통과했다. 위치 대각선 비율 0.003·배율 0.003·회전 0.3도 허용치는 변경하지 않았다.
- 추가 조사한 900점 사례는 실제 공유 표본 42.89%에 겹침률 70%를 강제하여 기존 점–점도 실패했다. 이번 결함만 재현하는 회귀가 아니므로 진단 자료로 분리하고 기존 5개 제품 회귀를 최종 기준으로 유지했다.
- 최종 ZIP의 격리 설치, 네 형상 조합의 정렬·승인·Undo/Redo 및 OBJ UV 왕복 검사 통과.
