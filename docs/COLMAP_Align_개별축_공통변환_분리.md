# 개별 원본 축과 데이터셋 공통 변환 분리

## 변경 범위

- COLMAP 점군·카메라와 연결 OBJ는 축 프리셋·Forward/Up만 각각 설정한다.
- 이동·회전·XYZ 배율·비율 잠금·원점 이동은 데이터셋 공통 설정 한 벌로 함께 적용한다. 회전·배율 중심은 존재하는 두 형상의 월드 경계 상자를 합친 중심이다.
- 축 설정 팝업이 열린 동안 대상 레이어의 실제 존재하는 점군·메시를 모두 표시한다. 미리보기 선택과 무관하게 비교할 수 있으며 기존 표시 토글과 눈 상태는 변경하거나 저장하지 않는다. 적용·취소·작업공간 이탈 시 표시 상태는 기존 값으로 돌아간다.
- 독립 OBJ와 COLMAP 단독 레이어는 있는 형상만 표시하고 설정한다.

## 변환과 호환성

1. 형상별 원본 축 `Aᵢ`, 데이터셋 공통 변환 `U`, 기존 개별 설정을 보존하는 기준 `Kᵢ`를 분리한다. 최종 표시 행렬은 `Nᵢ = U Kᵢ Aᵢ`다. 기존 공통 정렬 `C`는 그대로 유지한다.
2. 편집 시작 시 `Kᵢ = U⁻¹ Nᵢ Aᵢ⁻¹`로 기존 배치를 보존한다. 개별 축 조작은 해당 `Aᵢ`만, 공통 조작은 두 형상의 `U`를 함께 바꾼다. 원본 배열과 파일을 수정하지 않는다.
3. 표시 변환의 원본 기준 행렬로 `Aᵢ⁻¹ Kᵢ Aᵢ`를 보관한다. 공통 회전·이동·배율과 중심은 각 원본 축에 맞게 표현한다. 서로 다른 RC 원본 축과 기존 개별 비균일 배율도 손실 없이 유지한다.
4. 저장 스키마 10에 원본 기준 행렬을 추가하고 버전 1–9는 항등 기준으로 읽는다. 무변경 적용과 취소는 기존 float64 행렬·지문을 정확하게 유지한다. 확정·Undo/Redo는 기존 단일 편집 경계를 사용한다.
5. 개별 RC 초기화는 원본 축만 바꾼다. 데이터셋 변환 초기화는 공통 이동·회전·배율만 초기화한다. 기존 개별 보정은 호환 기준으로 유지한다.

## 검증 기준

- 원본 축만 개별 조절되고 이동·회전·비균일 배율은 같은 변화량으로 함께 적용된다.
- 전체 경계 중심 고정·월드 원점 이동·비율 잠금, COLMAP 단독·OBJ 단독·연결 OBJ.
- 존재하는 두 형상 동시 표시 및 미리보기 토글·취소·적용·작업공간 이탈 후 기존 표시 복원.
- 무변경 정밀도·원본 배열 보존·단일 Undo/Redo·구버전 읽기·새 설정 실제 저장과 복원.
- 실제 Blender RNA·팝업 화면, Align 필수 회귀·등록·정렬·배포 패키지 검사.

RNA 갱신 콜백은 [Blender 공식 속성 API](https://docs.blender.org/api/main/bpy.props.html)의 연산자 속성 래퍼에서도 편집 토큰으로 동작한다.

## 구현·검증 결과

- 버전 0.3.72: 개별 원본 축 박스 두 개와 데이터셋 공통 변환 박스 한 개로 UI를 분리했다. 존재하지 않는 형상 박스는 표시하지 않는다.
- Align 필수 회귀 45개 파일 통과. 신규 검사에서 기존 개별 배치·비균일 배율 보존, 공통 변화량, 전체 중심·원점 이동, 실제 RNA 자물쇠, 무변경 정밀도, Undo/Redo와 저장·복원을 확인했다.
- 별도 숨김 Blender GUI에서 원래 숨겨진 레이어의 실제 점군·표면 GPU 배치를 함께 그렸고 팝업 화면을 확인했다. 실제 키 이벤트로 취소·적용·작업공간 이탈, 독립 OBJ 팝업을 검증했다.
- 빌드 검사 298개, 통합 등록·해제, CCCoreLib 스테이징 실제 정렬과 격리 ZIP 설치 검사가 통과했다.
- 최상위 `colmap_tools.zip`을 0.3.72로 갱신하고 실제 사용자 설치본의 관련 파일 12개만 교체했다. 각 설치 파일은 ZIP·소스와 해시가 같으며 별도 프로세스에서 새 공통 변환 RNA·저장 버전·등록과 해제를 확인했다.
- 검증 자료: `build/verification/axis-split-20261001/`. 열려 있는 Blender 프로젝트는 저장하거나 다시 불러오지 않았다. 실행 중인 기존 버전은 Blender를 재시작한 뒤 교체된다.
