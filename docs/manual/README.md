# COLMAP Tools 사용자 매뉴얼 구성안

- 작성일: 2026-09-06
- 기준 버전: 정식 `COLMAP Tools 0.3.37`
- 기준 환경: Windows x64, Blender 5.2.0 이상. 화면과 조작 검증은 Blender 5.2를 기준으로 한다.
- 문서 상태: 목차와 장별 작성 범위를 정한 초안. 상세 사용 절차와 화면 자료는 이후 작성한다.

## 1. 대상 독자와 작성 목표

COLMAP 데이터와 스캔 메시를 Blender에서 정렬·편집하고, 촬영 이미지를 사용해 텍스처를 보정하려는 사용자를 대상으로 한다. Blender의 파일 열기, 기본 화면 이동, 오브젝트 선택 정도를 알고 있다고 가정한다.

사용자가 자신의 목적에 맞는 도구를 고르고, 데이터를 준비하고, 결과를 확인해 저장·내보내기까지 완료할 수 있도록 설명한다. 각 기능은 사용 목적, 준비물, 조작 순서, 기대 결과를 중심으로 작성한다.

## 2. 처음에 설명할 도구 관계

| 사용자 목적 | 사용할 도구 | 기본 작업 흐름 |
|---|---|---|
| 여러 COLMAP 데이터나 메시의 위치·방향·크기 맞추기 | COLMAP Align | 불러오기 → 기준·이동 대상 설정 → 정렬 → 결과 승인 → 내보내기 |
| COLMAP 점과 카메라를 검토하고 불필요한 데이터 제거하기 | COLMAP Modifier | 불러오기 → 점·카메라 검토 → 편집 → 내보내기 |
| 촬영 이미지를 이용해 모델 텍스처 보정하기 | Projection Painting | Modifier에서 데이터 준비 → 데이터 업데이트 → 페인트 대상 준비 → 페인팅 → 텍스처 내보내기 |

세 도구를 반드시 순서대로 실행할 필요는 없다. Align 데이터는 다른 두 도구와 독립적이며, Align 결과를 Modifier에서 사용하려면 내보낸 COLMAP 데이터를 Modifier로 불러온다.

Projection Painting의 `COLMAP 데이터 업데이트`는 그 시점의 Modifier 데이터를 독립적으로 복사한다. 이후 Modifier에서 편집해도 자동 반영되지 않으며, 새 결과가 필요할 때 사용자가 다시 업데이트한다. 이 관계를 첫 장의 간단한 데이터 흐름 그림과 함께 설명한다.

## 4. 장별 작성 범위

### 01. 제품 소개와 도구 선택

- 각 도구의 목적, 입력, 결과물과 대표 사용 사례.
- 도구 간 데이터 전달과 수동 업데이트 관계.
- 정렬된 COLMAP, 편집된 COLMAP, 정렬된 OBJ, 보정한 텍스처의 차이.
- 필요한 장을 바로 찾을 수 있는 목적별 읽기 안내.

### 02. 설치와 초기 설정

- 지원 환경과 정식 배포 ZIP 준비.
- Blender에서 확장을 설치하고 활성화하는 절차, 버전 확인과 업데이트 후 재시작.
- `Window → COLMAP Tools`에서 세 도구를 여는 방법.
- 기본 CC 정렬 실행 환경이 배포본에 포함된다는 안내와 `CC 정렬 환경 검사` 사용법.
- `CPU 스레드`의 의미: 0은 자동, 1은 단일 스레드, 2 이상은 사용 상한. 변경값은 다음 정렬부터 적용.
- Blender 기본 키맵과 Industry Compatible 키맵 확인. 확장 설치와 사용자 키맵 설정을 구분해 안내.

### 03. 입력 데이터 준비

- COLMAP의 `images`와 `sparse` 역할, 모델 하위 폴더와 바이너리·텍스트 형식 구분.
- 불러오기 창에서 선택할 폴더를 실제 지원 구조별 예시로 설명.
- COLMAP에 연결할 OBJ의 위치와 자동 검색·선택 조건, 독립 OBJ 입력의 차이.
- 점군과 메시의 좌표축·위치·단위가 같은지 확인하는 방법.
- RC에서 내보낸 COLMAP·OBJ를 함께 사용할 때 축 확인과 보정 흐름.
- OBJ 면, UV, 재질, 외부 텍스처의 역할과 도구별 필요 조건.
- Projection Painting에 필요한 카메라 이미지, 페인트 대상 모델, UV와 텍스처 준비.

### 04. 공통 화면과 기본 조작

- 도구별 작업공간, 3D 화면, 사이드 패널, 타임라인의 역할.
- 메뉴 진입, 작업공간 탭 이동, 다른 도구로 전환하고 돌아오는 방법.
- 데이터가 다른 작업공간에서 숨겨지는 동작과 실제 삭제의 차이.
- 키맵별 회전·이동·확대 조작과 도구 전용 단축키의 적용 범위.
- 선택, 실제 편집 대상, 눈 아이콘의 표시 상태를 구분하는 방법.
- 불러오기·복원·정렬·내보내기의 진행 안내, 취소와 완료 확인.
- 되돌리기의 적용 범위는 각 도구 장에서 별도로 설명한다는 안내.

### 05. 빠른 시작

서로 독립된 세 예제로 작성한다. 각 예제에는 준비 파일, 시작 화면, 최소 조작 순서, 성공 화면, 출력 파일을 포함한다.

1. **Align:** 두 데이터를 불러오고 대응점 세 쌍으로 초기 정렬한 뒤 CC 정렬, 승인, 내보내기까지 진행한다.
2. **Modifier:** COLMAP을 불러오고 점·카메라 일부를 검토·제거한 뒤 되돌리기와 내보내기를 확인한다.
3. **Projection Painting:** Modifier 데이터를 업데이트하고 페인트 대상과 레이어를 준비한 뒤 한 카메라 이미지로 칠하고 텍스처를 내보낸다.

### 06. COLMAP Align

- **화면 읽기:** 기준 A와 이동 P, 데이터 레이어, 마커, 정렬 상태와 출력 영역.
- **데이터 불러오기:** COLMAP, 연결 OBJ, 독립 OBJ와 추가 레이어 관리.
- **표시와 입력 선택:** 레이어별 점군·표면 선택, 전체 표시, 축 설정 아이콘. 눈으로 숨긴 A도 정렬 기준에 포함되는 조건을 명확히 설명.
- **축 설정:** COLMAP과 OBJ 각각의 축을 확인하고 미리보기·적용·취소하는 절차.
- **마커 지정:** 대응점 추가·편집·삭제, 점 또는 표면에서 선택, A끼리와 P끼리 형상 종류를 유지하는 규칙. A와 P는 서로 다른 종류를 사용할 수 있음.
- **3점 초기 정렬:** 대응점 배치 요령, 미리보기, 마커 기반 배율 옵션과 퇴화된 배치에 대한 안내.
- **CC 정밀 정렬:** 마커 미리보기에서 시작하는 흐름과 현재 위치에서 직접 시작하는 흐름.
- **입력 조합:** 점군→점군, 점군→표면, 표면→점군, 표면→표면의 자동 선택. 화살표는 이동 P에서 기준 A로의 방향으로 통일.
- **배율 보정:** CC 시작값 대비 최대 ±10% 균일 배율 보정과 마커 배율 옵션의 차이.
- **결과 판단:** 정렬 전후 시각 비교, 상태·수치 읽기, 정렬 승인과 결과 버리기, 되돌리기·다시 실행.
- **내보내기:** COLMAP 통합 출력과 OBJ 출력의 차이, 대상·경로 선택, 완료 결과 확인.
- **메시 보존:** 정렬은 삼각형 계산 데이터를 사용하지만 OBJ 출력에는 내장한 원본 면·UV와 확정 변환을 사용한다는 설명. 쿼드·N곤 보존과 텍스처 파일 전달 범위를 함께 안내.
- **정렬 품질:** 겹치는 부분, 초기 위치, 서로 다른 복원 형상에 따른 결과 차이. 외부 RC 재구성 결과는 별도로 확인하는 절차.

### 07. COLMAP Modifier

- **불러오기:** 데이터 루트, 표시 축, 점 크기와 카메라 크기 설정.
- **점 편집:** 점 편집 모드, 선택, 해당 점을 관측한 카메라 찾기, 제거.
- **카메라 편집:** 카메라 편집 모드, 선택·제거와 관측 점에 미치는 영향.
- **카메라 검토:** 이미지·프레임 이동, 배경 이미지, 카메라 및 관측 정보 확인.
- **필터:** 대기 중인 필터 결과 확인, 적용, 마지막 필터 취소와 전체 해제의 차이.
- **편집 이력:** Modifier 전용 되돌리기·다시 실행·초기화와 다른 작업공간의 Blender 되돌리기 구분.
- **내보내기:** 출력 형식·경로·백업 옵션, COLMAP 원본 축 유지, 성공 후 편집 이력이 초기화되는 동작.
- **Painting으로 전달:** 확정한 데이터를 Projection Painting에서 수동 업데이트하는 순서.

### 08. Projection Painting

- **데이터 준비:** `COLMAP 데이터 업데이트`, 최초 복사와 재업데이트, Modifier 변경의 수동 반영.
- **페인트 준비:** 모델, UV, 단일 텍스처·UDIM 설정과 기존 텍스처 사용.
- **카메라 검토:** 촬영 이미지·프레임 선택, 카메라 화면과 일반 화면 이동.
- **스텐실 연결:** 연결 조건, 명시적인 재연결, F6의 적용 문맥과 일시 중지 상태.
- **브러시 사용:** 그리기·복제·번짐·흐림·채우기·마스크 도구와 카메라 스텐실의 관계.
- **레이어:** 생성·정렬·삭제, 한 번 클릭하는 선택과 더블클릭하는 실제 편집 활성화의 차이, 복수 선택.
- **표시와 마스크:** 눈 아이콘, 단독 보기, 레이어 마스크와 보정 마스크의 역할.
- **원본과 합성:** 원본 레이어, 보정, 합성 레이어의 생성·해제·재생성과 편집 범위.
- **텍스처 출력:** 현재 눈이 켜진 레이어와 마스크·보정·순서가 반영되는 `Export Texture`. 단독 보기와 출력 대상의 차이.
- **완료 확인:** 진행률·취소·덮어쓰기, 출력 이미지의 색·알파·해상도·UDIM 확인.

### 09. 프로젝트 저장과 다시 열기

- `.blend` 저장과 COLMAP·OBJ·텍스처 내보내기의 목적 차이.
- 도구별로 파일에 저장되는 상태와 다시 열 때 필요한 외부 파일을 표로 정리.
- Align의 내장 OBJ 면·UV, 마커와 확정 변환 복원. COLMAP 원본은 외부 참조라는 점을 설명.
- OBJ 형상 내장과 외부 텍스처 이미지의 저장은 별개임을 설명.
- Align 작업공간에서 저장한 파일의 자동 세션 연결과 일반 작업공간에서 저장한 파일의 화면 유지.
- Modifier의 원본·편집 기록 복원, 필요한 시점의 로딩과 진행 안내, 다시 열었을 때의 되돌리기 범위.
- Projection Painting의 독립 데이터와 레이어·페인트 상태, 원본 이미지·텍스처의 보관 조건.
- 폴더 이동·다른 컴퓨터로 전달할 때 함께 보관할 파일, 원본 누락과 재연결 처리.
- 구버전 프로젝트의 재불러오기 필요 조건은 도구별로 구분.

### 10. 문제 해결과 참고표

| 분류 | 설명할 대표 증상 | 우선 확인할 항목 |
|---|---|---|
| 설치·실행 | 메뉴가 없거나 CC 정렬을 시작할 수 없음 | 확장 활성화, 버전, CC 환경 검사 결과 |
| 입력·축 | 불러오기가 실패하거나 점군과 메시가 다른 방향 | 선택 폴더, 원본 존재, 좌표축·위치·단위 |
| 정렬 | 마커가 선택되지 않거나 정렬 결과가 기대와 다름 | A/P, 형상 종류 고정, 초기 배치, 겹치는 영역 |
| 저장·복구 | 세션 연결 안내가 계속되거나 원본 필요 표시 | 복원 진행·오류 안내, 외부 원본 경로, 재연결 |
| Modifier | 삭제 대상·필터·되돌리기가 예상과 다름 | 편집 모드, 대기 필터, 전용 이력, 내보내기 여부 |
| Painting | 칠해지지 않거나 다른 레이어에 칠해짐 | 실제 활성 대상, 잠금, 도구·브러시, 스텐실 상태 |
| 출력 | 화면과 텍스처 결과가 다르거나 파일 출력 실패 | 눈 상태, 단독 보기, 출력 경로, 쓰기 권한 |
| 성능 | 불러오기·정렬·텍스처 출력이 오래 걸림 | 현재 작업 단계, 입력 크기, 해상도, CPU 설정 |

부록에는 도구·작업공간별 단축키 표와 점군, 표면, A/P, 좌표축, 균일 배율, UV, UDIM, 스텐실, 합성, 데이터 복사본에 대한 짧은 용어집을 둔다. 문제 보고 시 필요한 버전·실행 단계·오류 문구·화면과 재현 조건도 안내한다.

## 5. 상세 항목 작성 형식

각 사용 절차는 다음 순서로 통일한다.

1. **목적:** 이 기능으로 얻는 결과.
2. **시작 조건:** 필요한 파일, 작업공간, 선택·활성 상태.
3. **조작 순서:** 실제 메뉴·버튼 이름을 사용한 번호형 단계.
4. **결과 확인:** 화면과 출력 파일에서 확인할 항목.
5. **취소·되돌리기:** 확정 전 취소와 확정 후 복구 범위.
6. **관련 문제:** 해당 절차에 직접 관련된 오류와 해결 항목 연결.

설명은 한국어로 작성하되 화면의 제품명·버튼명은 실제 표시를 병기한다. 단축키에는 적용 작업공간과 키맵을 표시한다. 같은 이름의 표시 설정이라도 도구별 영향이 다르면 따로 설명한다.

## 6. 화면 자료와 예제 준비

실제 정식 설치본에서 캡처한 화면을 사용하고, 버튼·아이콘·선택 상태에 번호를 붙인다. 저장 위치는 상세 집필 시 `docs/manual/images/` 아래를 사용한다.

| 자료 | 반드시 보여줄 내용 |
|---|---|
| 도구 관계 그림 | Align의 독립 입출력과 Modifier→Painting 수동 복사 |
| 설치·환경설정 | 확장 버전, 도구 메뉴, CPU 설정, CC 환경 검사 |
| 입력 폴더 예시 | `images`·`sparse`·연결 OBJ 위치와 선택할 폴더 |
| Align 전체 화면 | A/P, 레이어 형상·축·눈 아이콘, 마커, 승인 전후 |
| Modifier 전체 화면 | 점·카메라 편집, 관측 관계, 대기 필터, 내보내기 |
| Painting 전체 화면 | 카메라 이미지, 연결 상태, 선택·활성 레이어, 출력 눈 상태 |
| 저장·복원 예시 | 정상 재진입, 외부 원본 누락, 다시 연결 안내 |

예제는 작은 데이터로 구성하고 입력 원본과 생성 결과를 구분한다. 이미지·모델은 배포 가능한 자료만 사용하며, 개인 경로는 예제용 경로로 표기한다. 폴더 그림이나 예정 화면은 실제 동작 검증 자료와 구분한다.

## 7. 집필 순서와 완료 기준

집필은 **빠른 시작과 Align → Modifier → Projection Painting → 저장·복구와 문제 해결** 순서로 진행한다. 설치·공통 조작·입력 준비는 첫 단계와 함께 작성하고, 최종적으로 전체 목차 순서로 연결한다.

- 모든 상세 절차를 정식 설치본에서 직접 따라 할 수 있다.
- 화면 자료의 메뉴·버튼 이름이 기준 버전과 일치한다.
- 표시 변경, 편집, 결과 승인, 파일 저장과 내보내기의 차이를 확인할 수 있다.
- 도구 사이 자동 동기화 여부와 외부 파일 의존성을 각 관련 장에서 설명한다.
- 예제마다 완료 화면과 결과물을 확인할 기준이 있다.
- 개발용 실험 환경·빌드 명령·벤치마크 수치를 일반 사용자 필수 절차에 넣지 않는다.
- 아직 검증하지 않은 세부 절차는 확인 대상으로 표시하고 지원 기능처럼 단정하지 않는다.
