# Projection Paint 기능 매뉴얼

촬영 이미지를 모델 표면에 투영해 텍스처를 보정하고, 레이어·마스크·색 보정을 합성하여 이미지로 출력하는 도구입니다. 실제 Blender 메뉴 이름은 **Projection Painting**입니다.

- 기준: **COLMAP Tools 0.3.74 · Windows x64 · Blender 5.2.0 이상**.
- 실행: **Window → COLMAP Tools → Projection Painting**.
- [설치·공통 조작](README.md) · [Align](ALIGN.md) · [Modifier](MODIFIER.md).
- 캡처는 사용자가 직접 추가합니다. 각 기능 옆 상자에 준비 상태와 예정 파일명을 표시했습니다.

## 1. COLMAP·OBJ 불러오기

**용도:** COLMAP 파일의 점군·카메라·촬영 이미지와 OBJ 모델을 직접 사용합니다. Modifier나 Align을 먼저 실행할 필요가 없습니다.

**위치:** **COLMAP Dataset → COLMAP 불러오기 / OBJ 불러오기**.

입력 영역에는 두 버튼을 각각 한 줄씩 표시합니다. 경로·파일 형식·원본 축 입력란은 패널에 표시하지 않습니다.

1. **Window → COLMAP Tools → Projection Painting**을 엽니다.
2. **COLMAP 불러오기**에서 희소 모델과 촬영 이미지가 있는 데이터셋 폴더를 선택합니다. 파일 탐색기의 **참고 점 최대 개수**는 기본 20,000개이며 필요하면 변경할 수 있습니다. 카메라·촬영 이미지는 모두 가져옵니다.
3. 선택한 폴더에서 희소 모델과 촬영 이미지를 자동 탐색합니다. TXT·BIN을 지원합니다.
4. **OBJ 불러오기**로 메시를 가져옵니다. 원본 UV·재질·텍스처 연결을 유지합니다.
5. **Paint Setup → Paint Target**에서 사용할 메시를 지정합니다.

COLMAP 재입력은 카메라·점군만 교체하며 기존 메시·페인트 대상·레이어를 유지합니다. OBJ는 새 메시로 추가하며 기존 페인트 대상을 자동 교체하지 않습니다. 기본 OBJ 가져오기 호출 도중에는 즉시 취소할 수 없습니다.

**사용 조건:** 촬영 이미지가 지정 경로에 있어야 하며 정확한 투영은 `SIMPLE_PINHOLE`·`PINHOLE` 카메라를 사용합니다. 페인팅 중에는 입력을 바꿀 수 없습니다. Modifier 편집 결과는 [COLMAP Export](MODIFIER.md#export) 후 파일로 불러옵니다.

**결과:** 파일에서 가져온 독립 데이터가 준비됩니다. COLMAP Dataset의 Point Display·Camera Display로 점과 카메라 표시 크기를 조절할 수 있습니다.

점 상한은 새 COLMAP 가져오기에 적용합니다. 파일 탐색기를 취소하면 기존 경로와 상한이 유지되고, 이미 저장된 점군을 열거나 페인팅에 진입할 때 자동 축소하지 않습니다. 표본을 가져온 경우 Dataset에 원본 점 수를 함께 표시합니다.

## 2. Paint Target·Painting Mode

**용도:** 칠할 모델과 해상도를 정하고 페인트 작업을 시작하거나 종료합니다.

**위치:** **Paint Setup → Paint Target / Use Base Resolution / Resolution / Painting Mode**.

### 페인트 대상 준비

- 파일에서 직접 불러올 COLMAP과 해당 촬영 이미지.
- COLMAP과 좌표가 맞는 **실제 Blender Mesh 오브젝트**.
- 페인트 대상 모델의 유효한 UV Map.
- 기존 색상 텍스처를 유지하려면 올바른 재질·이미지 연결.

Align 내부에 내장된 메시는 일반 Blender 페인트 대상과 다릅니다. Align에서 정렬한 메시로 칠하려면 OBJ로 내보낸 뒤 Painting의 **OBJ 불러오기**로 가져옵니다.

연결 라이브러리 메시를 사용한다면 로컬 복사본을 준비하십시오. 여러 오브젝트가 같은 Mesh 데이터를 공유한다면 페인트 대상의 Mesh를 **Single User**로 분리해야 합니다. Painting 준비 과정에서 UV와 재질 구성을 관리하므로 작업 전 `.blend` 복사본을 저장해 두면 원래 모델 구성을 보관할 수 있습니다.

기존 재질을 사용할 때는 노드를 사용하는 재질과 Material Output의 Surface에 연결된 Principled BSDF가 필요합니다. Base Color에 직접 연결된 이미지 텍스처는 원본 이미지로 인식할 수 있습니다. 대상 준비가 거부되면 상태 메시지에 표시된 UV·재질·Mesh 조건을 확인합니다.

### 대상 지정과 시작·종료

1. Painting의 **OBJ 불러오기**로 모델을 가져오거나 기존 실제 메시를 준비하고 COLMAP과 위치·축이 맞는지 확인합니다.
2. Painting의 **Paint Setup**을 펼칩니다.
3. **Paint Target**에 해당 Mesh 오브젝트를 지정합니다.
4. 기존 텍스처 해상도를 사용할 때는 **Use Base Resolution**을 확인합니다. 직접 지정할 때는 **Resolution**을 설정합니다.
5. **Painting Mode**를 누르고 준비가 끝날 때까지 기다립니다.
6. 상태에서 Painting이 활성화되었는지 확인합니다.

UV가 없거나 페인트 대상이 공유 Mesh·연결 라이브러리 상태라면 위 페인트 대상 준비의 조건에 맞게 정리합니다. 높은 해상도, 많은 UDIM 타일과 레이어는 메모리를 더 사용합니다. 처음에는 작은 해상도에서 흐름을 확인한 뒤 실제 작업에 필요한 값으로 설정하십시오.

Painting Mode를 종료하려면 같은 버튼을 사용합니다. 페인트 모드에서 나오는 것과 텍스처를 파일로 저장하는 것은 별개입니다.

진입할 때 페인트 색상은 흰색으로 설정되고 **페인트 대상 외의 메시·조명·빈 오브젝트는 숨겨집니다**. 점군과 카메라 등 보조 윤곽도 표시하지 않습니다. 배경용 카메라 자체와 촬영 이미지 연결은 유지하므로 **Camera Review → Background**를 켜면 카메라 배경 사진이 표시됩니다. 종료하면 다른 오브젝트·참고 표시·보조 윤곽 설정은 원래 상태로 돌아갑니다. 원래 숨긴 오브젝트는 계속 숨기며 페인트 중 직접 다시 표시한 오브젝트는 종료 때 덮어쓰지 않습니다. 진입한 뒤에는 색상을 원하는 값으로 바꿀 수 있습니다.

카메라뷰에서 일반 뷰로 나오면 원근투영으로 복귀합니다. 일반 뷰에서 직접 정사투영을 선택하는 기본 Blender 조작은 유지됩니다.

**Use Base Resolution**을 켠 채 다시 진입해도 보존된 원본 해상도를 사용하고 기존 페인트 레이어를 유지합니다. 옵션을 끄고 다른 해상도를 지정하면 전체 레이어 초기화 확인이 필요합니다.

**결과:** 지정한 모델이 페인트 대상이 됩니다. 실제로 칠할 레이어는 [Layers에서 별도로 활성화](#layers)합니다.

## 3. 레이어 관리

**용도:** 페인트를 여러 레이어로 나누고 실제로 칠할 대상을 선택합니다.

**위치:** **Layers** 목록과 +/−·위/아래 버튼, 레이어 문맥 메뉴.

**Layers**에서 레이어를 한 번 클릭하면 선택만 바뀝니다. **수정키 없이 더블클릭해야 실제 페인트 대상이 활성화됩니다.** 파란 선택 배경만 보고 칠할 레이어가 바뀌었다고 판단하지 말고 활성 표시까지 확인합니다.

| 조작 | 용도 |
|---|---|
| 한 번 클릭 | 목록에서 항목 선택 |
| 더블클릭 | 레이어·마스크 등 실제 편집 대상 활성화 |
| Ctrl/Shift 선택 | 여러 항목 선택 |
| `+` | 새 일반 페인트 레이어 추가 |
| `-` | 선택된 항목 삭제 |
| 위·아래 이동 | 레이어 순서 변경 |
| 눈 아이콘 | 합성과 텍스처 출력에 포함할지 설정 |
| 단독 보기 | 해당 레이어 또는 마스크를 집중해서 확인 |

레이어 목록 문맥에서 `Delete`는 **선택된 항목**을 삭제합니다. 실제로 칠하고 있던 활성 레이어만 지우는 기능이 아닙니다. 복수 선택 중에는 스트로크가 제한될 수 있으므로 칠할 항목 하나를 명확히 활성화합니다.

외부 이미지에서 가져온 **Original** 본체는 원본을 직접 칠하는 일반 레이어로 사용하지 않습니다. 원본 위에 새 일반 레이어를 추가해 보정하십시오. Original의 표시·마스크·색 보정과 Composite 참여는 별도로 사용할 수 있습니다.

이름을 바꾸려면 해당 레이어의 문맥 메뉴에서 **Rename Layer**를 사용합니다. 레이어 화살표를 펼치면 마스크와 보정 항목을 확인할 수 있습니다. Composite가 활성화되어 기존 Source가 잠겼다면 [Composite 해제](#composite) 후 수정합니다.

**결과:** 더블클릭한 편집 가능 항목이 실제 페인트 대상이 됩니다. 목록 선택과 활성 대상은 별도이므로 브러시를 사용하기 전에 활성 표시를 확인합니다.

## 4. 카메라 이미지 검토

**용도:** 칠할 부위가 잘 보이는 촬영 시점과 원본 이미지를 확인합니다.

**위치:** 타임라인과 **Camera Review**.

1. 타임라인에서 사용할 카메라 프레임을 선택합니다.
2. Camera Review의 **IMAGE_ID**와 이미지 정보를 확인합니다.
3. 프레임 변경으로 전환된 촬영 시점을 확인합니다.
4. **Show Background Image** 또는 `F7`로 배경 이미지를 켜거나 끕니다.
5. **Background Alpha**로 모델과 배경을 비교하기 좋은 표시 강도를 정합니다.

**결과:** 사용할 이미지와 시점을 검토할 수 있습니다. 배경 이미지 표시와 브러시 스텐실 연결은 별도 기능입니다. 실제 이미지로 칠하려면 [스텐실 재연결](#stencil)을 사용합니다.

## 5. 스텐실 재연결

**용도:** 현재 카메라 이미지를 모델에 칠할 Draw 브러시의 입력으로 연결합니다.

**위치:** **Paint Setup → Reconnect Stencil Texture**, 유효한 Painting 화면에서 **F6**.

1. 타임라인에서 사용할 카메라 프레임을 선택하거나 일반 원근 뷰에서 원하는 시점을 잡습니다.
2. **Camera Review**의 IMAGE_ID와 이미지 이름을 확인합니다.
3. 현재 뷰의 위치와 방향을 확인합니다.
4. 칠할 일반 레이어를 더블클릭해 활성화합니다.
5. **Reconnect Stencil Texture**를 누릅니다. 유효한 Painting 화면에서는 `F6`도 사용할 수 있습니다.
6. 상단 스텐실 상태가 연결되었는지 확인합니다.

재연결은 카메라 이미지를 쓰기 위한 프로젝트 Draw 브러시를 준비합니다. 다른 브러시를 골랐거나 마스크를 편집 중인 상태와 구분하십시오.

재연결 버튼은 현재 뷰의 위치·방향에 맞는 카메라를 찾아 해당 프레임과 카메라뷰로 이동하고 스텐실을 연결합니다. 별도의 **Look Through Camera** 버튼은 표시하지 않습니다.

카메라 화면 밖으로 나가면 카메라 스텐실 연결이 일시 중지됩니다. 점·레이어·이미지가 삭제된 것은 아닙니다. 카메라 화면으로 돌아와 상태를 확인하고 필요하면 재연결합니다. 프레임을 연속으로 빠르게 바꾸면 마지막 프레임에 잠시 멈춘 뒤 이미지가 갱신됩니다.

**F7은 카메라 배경 이미지 표시**, **F6는 스텐실 재연결**입니다. 배경 이미지가 보인다는 것만으로 브러시 스텐실이 연결되었다고 판단하지 않습니다.

## 6. 브러시 페인팅

**용도:** 필요한 표면만 부분적으로 칠하거나 기존 색을 복제·보정합니다.

**위치:** Painting 화면의 Blender 브러시 도구.

왼쪽 도구 막대, 상단 도구 설정과 브러시 자산 선반은 일반 Texture Paint 화면과 동일합니다. 도구 막대는 `T`로 표시하거나 숨길 수 있습니다. 브러시 도구는 **Painting Mode**로 텍스처 페인트에 진입한 뒤 표시됩니다.

1. 칠할 일반 레이어를 더블클릭하여 활성화합니다.
2. 촬영 이미지로 칠하려면 카메라 화면에서 [스텐실을 재연결](#stencil)합니다.
3. 브러시 크기·강도를 조절한 뒤 작은 부위에 시험합니다.
4. 레이어와 투영 상태를 확인하고 필요한 부위를 칠합니다.

| 도구 | 용도 |
|---|---|
| Draw | 선택한 색이나 연결한 촬영 이미지로 칠하기 |
| Blur | 색 경계를 부드럽게 보정 |
| Smear | 기존 색을 문질러 펴기 |
| Clone | 현재 활성 이미지의 다른 위치에서 색 복제 |
| Fill | 선택한 채우기 설정으로 색 적용 |
| Mask | 페인트 적용 범위를 제한하는 마스크 작업 |

브러시는 Blender 기본 도구 동작을 따릅니다. Clone의 복제 원점은 Blender의 `Ctrl` + 왼쪽 클릭 방식으로 지정합니다. 도구를 바꾸면 현재 브러시와 실제 활성 레이어를 다시 확인합니다. 레이어 마스크 편집 중에는 카메라 스텐실을 사용하지 않습니다.

**되돌리기:** 시험 스트로크나 잘못된 페인트는 Painting 화면의 Blender Undo를 사용합니다. Modifier 전용 편집 이력과 별개입니다.

<a id="project"></a>

## 7. Project Stencil to Target

**용도:** 현재 카메라 이미지를 그 시점에서 보이는 대상 표면에 한 번에 투영합니다.

**위치:** **Paint Setup → Project Stencil to Target**.

1. Painting Mode와 사용할 카메라 화면을 확인합니다.
2. 투영 결과를 받을 일반 레이어를 더블클릭합니다.
3. [Reconnect Stencil Texture](#stencil)로 촬영 이미지를 연결합니다.
4. **Project Stencil to Target**을 실행합니다.
5. 현재 카메라에서 보이는 표면의 색을 확인합니다.

**결과:** 현재 카메라에 보이는 표면으로 투영됩니다. 다른 촬영 이미지까지 자동으로 순회하는 기능은 아닙니다. 특정 부분만 보정하려면 [브러시 페인팅](#brushes)을 사용합니다.

<a id="masks"></a>

## 8. 마스크·색 보정

**용도:** 레이어가 적용되는 범위와 색을 조절합니다.

**위치:** **Layers**의 레이어·보정 행 문맥 메뉴와 보정 설정.

### 레이어 마스크

1. 대상 레이어의 문맥 메뉴에서 **Add Mask**를 선택합니다.
2. 레이어 아래의 Mask 행을 더블클릭하여 활성화합니다.
3. 마스크를 칠해 적용 범위를 조절하고 모델에서 결과를 확인합니다.

레이어 마스크는 해당 레이어 전체의 적용 범위를 제한합니다. 마스크 편집 중에는 카메라 스텐실 투영을 사용하지 않습니다.

### 색 보정과 보정 마스크

1. 레이어 문맥 메뉴의 **Add Adjustment**에서 필요한 보정을 추가합니다.
2. 보정 항목을 선택하고 패널의 값을 조절합니다.
3. 일부 영역만 보정하려면 해당 보정 행의 문맥 메뉴에서 **Add Mask**를 사용합니다.
4. 보정 마스크 행을 더블클릭하여 적용 범위를 칠합니다.

| 보정 메뉴 | 조절 내용 |
|---|---|
| Add Brightness | 밝기 |
| Add Exposure | 노출 |
| Add Hue/Saturation | 색상·채도 |

**Enabled**로 보정 적용 여부를 바꿀 수 있습니다. 보정 마스크는 해당 보정에만 영향을 줍니다. 마스크·보정의 문맥 메뉴에서 삭제할 때는 대상 행을 확인합니다.

**결과:** 레이어 원본 색과 별도로 범위·색을 조절하며, 적용 중인 마스크와 보정은 [텍스처 출력](#export)에 반영됩니다. Original 레이어의 마스크·보정도 사용할 수 있습니다.

<a id="visibility"></a>

## 9. 눈·단독 보기

**용도:** 레이어의 출력 포함 여부를 정하고 특정 레이어나 마스크를 집중해서 확인합니다.

**위치:** **Layers**의 눈 아이콘과 단독 보기.

| 표시 기능 | 동작 |
|---|---|
| 눈 아이콘 | 합성과 텍스처 출력에 포함할지 설정 |
| 레이어 단독 보기 | 그 레이어의 색·알파·마스크·보정을 검정 배경에서 확인 |
| 마스크 단독 보기 | 마스크를 흑백으로 확인 |

**단독 보기는 출력 범위를 정하지 않습니다.** Export Texture는 눈이 켜진 레이어의 순서·마스크·보정을 반영합니다. 특정 레이어만 출력하려면 눈 상태를 확인하십시오.

<a id="composite"></a>

## 10. Composite

**용도:** 여러 레이어의 합성 결과를 만들고 그 결과에 직접 페인트합니다.

**위치:** **Layers → Composite Layer 생성 / Composite 해제 / Composite 다시 생성**.

여러 레이어를 하나의 합성 결과로 다루려면 **Composite Layer 생성**을 사용합니다. 합성에 참여한 Source 레이어는 잠기고 Composite를 직접 편집할 수 있습니다. 그 이후 추가한 일반 레이어도 별도로 편집할 수 있습니다.

Source를 다시 수정해야 한다면 **Composite 해제** 후 작업합니다. **Composite 다시 생성**은 합성을 다시 만드는 작업이므로 Composite에 직접 칠한 결과를 재생성 전에 `.blend`와 출력 텍스처로 보관하십시오. 합성을 내보내기 위해 Composite를 반드시 만들 필요는 없습니다.

<a id="capture-20"></a>

> **[캡처 20] 마스크와 Composite**
>
> - 준비: 마스크·색 보정이 있는 레이어와 Composite를 만든 상태. 필요하면 생성 전후 두 컷 사용.
> - 필수 표시: 마스크/보정 행, Composite, 잠긴 Source, Composite 생성·해제·다시 생성 위치.

<a id="export"></a>

## 11. Export Texture

**용도:** 현재 레이어 합성 결과를 다른 프로그램에서 사용할 이미지로 저장합니다.

**위치:** **Layers → Export Texture**.

1. 출력할 레이어의 **눈 상태**를 확인합니다.
2. 레이어 순서·마스크·보정을 확인합니다. 단독 보기로 보이는 화면만 출력된다고 생각하지 않습니다.
3. **Export Texture**를 누릅니다.
4. 파일 브라우저에서 출력 방식과 형식을 선택합니다.
5. 같은 이름의 결과를 바꿀 때만 **Overwrite Existing**을 켭니다.
6. 내보내기가 끝난 뒤 이미지 파일을 열어 색·알파·크기·타일을 확인합니다.

| 옵션 | 선택 기준 |
|---|---|
| Single Image | 단일 이미지. 논리 타일 1001 하나인 입력에 사용 |
| UDIM Tiles | UDIM 타일별 이미지 출력 |
| Atlas | 여러 타일을 한 이미지에 배치. Atlas Max Size로 긴 변 제한 |
| PNG / RGBA | 투명도까지 전달할 때 |
| PNG / RGB, JPEG | 알파가 필요하지 않을 때. JPEG는 알파를 저장하지 않음 |
| UDIM Naming | `name.1001.png` 또는 `name.u1_v1.png` 형식 |
| Overwrite Existing | 기존 출력 파일 교체 허용 |

출력은 눈이 켜진 레이어의 색·알파·순서·마스크·보정을 반영합니다. 활성 Composite의 Source를 중복 합성하지 않습니다. 모든 레이어의 눈이 꺼져 있다면 출력할 수 없습니다.

**Atlas 출력은 현재 모델의 UV를 자동으로 바꾸지 않습니다.** Atlas를 다른 프로그램에서 사용하려면 그 배치에 맞는 UV를 별도로 준비해야 합니다. 원래 UDIM UV를 유지할 때는 UDIM Tiles 출력을 사용합니다.

내보내기 중에는 진행창을 확인합니다. Bake 단계는 고정 백분율 대신 작업 단계와 경과 시간이 표시될 수 있습니다. 취소하려면 `Esc`를 누르고 내부 작업이 끝날 때까지 기다립니다. 완료 전에 Blender를 강제로 닫지 않습니다.

<a id="capture-21"></a>

> **[캡처 21] 텍스처 출력 옵션**
>
> - 준비: Export Texture 파일 브라우저. UDIM 입력이면 Output 옵션이 보이게 촬영.
> - 필수 표시: Output, Format, Color, UDIM Naming 또는 Atlas Max Size, Overwrite Existing. 완료 이미지/파일명은 보조 컷으로 추가 가능.
> - 예정 파일: `images/21-painting-texture-export.png`

<a id="save"></a>

## 12. 저장·작업 복원

**용도:** 복사한 COLMAP 데이터와 페인트 모델·레이어·작업 상태를 보관합니다.

**위치:** Blender **File → Save / Save As**, 필요할 때 **Export Texture**.

1. 진행 중인 투영·내보내기 작업이 끝났는지 확인합니다.
2. `.blend`를 저장합니다.
3. 다른 프로그램에서 사용할 결과는 [Export Texture](#export)로 별도 저장합니다.
4. 촬영 이미지와 외부 Original·텍스처 이미지의 저장 상태 및 경로를 확인합니다.
5. 다른 위치로 전달할 때는 외부 이미지도 함께 옮기고 다시 열어 확인합니다.

`.blend`에는 복사한 COLMAP 데이터와 레이어·페인트·연결 상태가 남습니다. 모든 외부 이미지가 자동으로 내장된다고 가정하지 않습니다.

다시 열린 Painting 데이터는 Modifier와 독립적으로 유지되며 이전 Modifier 복사 자료도 복원합니다. 최신 Modifier 편집은 COLMAP으로 내보낸 뒤 [COLMAP 불러오기](#dataset)로 가져옵니다. Painting Mode 종료와 `.blend` 저장, 텍스처 Export는 각각 별도 작업입니다.

## 13. 문제 해결·단축키

| 증상 | 확인할 기능 |
|---|---|
| COLMAP·OBJ 불러오기가 비활성 | 페인팅 또는 다른 가져오기가 진행 중인지 확인 |
| Painting Mode를 시작할 수 없음 | [Paint Target](#paint-target)의 UV·로컬 Mesh·Single User·재질과 상태 메시지 |
| 다른 레이어에 칠해짐 | 선택만 바꾼 상태일 수 있음. [더블클릭과 활성 표시](#layers) 확인 |
| 레이어를 편집하거나 순서를 바꿀 수 없음 | Original의 편집 제한, [Composite Source 잠금](#composite) 확인 |
| 배경은 보이는데 이미지로 칠해지지 않음 | 배경과 스텐실은 별도. 일반 레이어·Draw·카메라 화면에서 [F6 재연결](#stencil) |
| 카메라 화면을 벗어나면 스텐실이 멈춤 | 일시 중지 상태. 카메라 화면으로 돌아와 연결 상태 확인 |
| 마스크에 촬영 이미지가 투영되지 않음 | 마스크 편집 중에는 스텐실을 사용하지 않음 |
| 화면과 출력 색이 다름 | [눈 상태·레이어 순서·마스크·보정](#visibility) 확인. 단독 보기는 출력 범위가 아님 |
| Atlas를 적용하면 UV가 어긋남 | [Atlas 출력](#export)은 UV를 자동 변경하지 않음. 별도 UV 준비 또는 UDIM Tiles 사용 |
| 다시 열면 이미지가 보이지 않음 | [외부 촬영 이미지·텍스처](#save)의 경로·저장 여부 |

| 입력 | Painting에서의 동작 |
|---|---|
| 레이어 한 번 클릭 | 목록 선택 |
| 수정키 없는 더블클릭 | 레이어·마스크 실제 편집 활성화 |
| Ctrl/Shift 선택 | 목록 복수 선택 |
| Delete | 레이어 목록 문맥의 선택 항목 삭제 |
| F6 | 유효한 세션에서 카메라 스텐실 재연결 |
| F7 | 카메라 배경 이미지 표시 전환 |
| Ctrl 누르기 / 놓기 | 연결된 스텐실에서 Erase Soft로 전환 / 이전 브러시 복귀 |
| Ctrl + 왼쪽 클릭 | Blender Clone 복제 원점 지정 |
| Esc | 텍스처 출력 진행 중 취소 요청 |
