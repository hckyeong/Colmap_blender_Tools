- 작성일: 2026-09-09

- 범위: 설치, 입력 준비, 공통 조작, 세 도구의 사용·저장·내보내기, 문제 해결.
- 산출물: 공통 안내 `README.md`와 기능별 매뉴얼 `ALIGN.md`, `MODIFIER.md`, `PROJECTION_PAINT.md`. 캡처는 사용자가 직접 추가한다.
- 변경 요청: 자동 캡처·Computer Use를 중지하고 필요한 화면의 위치와 촬영 조건만 표시한다.

## 진행 단계

1. 설치된 정식 확장 버전과 실제 메뉴·오퍼레이터를 확인한다.
2. 확인한 예제 실행과 현재 UI 코드에서 기능·버튼 이름·활성 조건을 대조한다. 사용자 작업 파일을 수정하거나 배포 예제로 포함하지 않는다.
3. 각 캡처 위치에 번호·예정 파일명·화면 준비 조건·필수 표시 항목을 기록한다. 아직 없는 이미지에 깨진 링크를 만들지 않는다.
4. 목적·준비물·조작 순서·결과·취소/되돌리기를 설명한다. 제품 내부 구현을 사용자 필수 절차에 넣지 않는다.
5. 문서 링크·캡처 번호·한국어 인코딩을 검증한다. 미촬영 상태와 검증 범위를 사실대로 기록한다.

## 완료 기준

- 세 도구의 전체 화면과 주요 기능 화면을 넣을 위치 및 촬영 조건을 포함한다.
- A/P·표시/입력 종류·선택/페인트 활성 상태·저장/내보내기의 차이를 설명한다.
- 지원 버전, 설치 ZIP, CPU 설정, 외부 파일 보관 조건을 명시한다.
- 개발 내부 구조·벤치마크를 필수 사용자 절차에 넣지 않는다.
- 소스 코드·사용자 환경설정은 수정하지 않으며 이번 문서 작업은 자동 커밋·푸시하지 않는다.

## 도구별 기능 매뉴얼 개편

- 사용자 요청에 따라 Align, Modifier, Projection Paint를 독립 문서로 나눈다. 실제 메뉴 이름이 Projection Painting인 점을 함께 안내한다.
- 긴 순서형 빠른 시작 대신 기능별 용도·버튼 위치·사용 조건·조작·결과 중심으로 구성한다.
- 저장·복원·내보내기·문제 해결은 각 도구 문서에 배치하고, 공통 안내에는 문서 선택·설치·실행·화면 탐색·캡처 삽입 방법을 둔다.
- 기존 캡처 번호 01–22와 예정 파일명은 유지하며 해당 기능 설명 옆으로 이동한다.
- 제품 기능과 버튼 설명은 기존에 확인한 현재 동작을 보존한다. 코드 수정, 자동 캡처, Blender 조작은 수행하지 않는다.
- 문서 간 링크, 기능 목차, 캡처 위치와 목록, UTF-8 인코딩을 검증한다.

- 화면 촬영·삽입 및 실제 화면과의 최종 대조는 사용자 작업으로 남아 있다.
