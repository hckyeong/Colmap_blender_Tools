# Align 기능 매뉴얼

COLMAP 희소 점군과 OBJ 메시의 위치·방향·크기를 맞추고, 확정한 결과를 COLMAP 또는 OBJ로 내보내는 도구입니다.

- 기준: **`codex/artec-align-engine`의 점 기반 강체·Sim(3) 정렬 배포판 · Windows x64 · Blender 5.2.0 이상**. 기존 CC 배포판의 정렬 지표·배율 보정과 구분합니다.
- 실행: **Window → COLMAP Tools → COLMAP Align**.
- [설치·공통 조작](README.md) · [Modifier](MODIFIER.md) · [Projection Paint](PROJECTION_PAINT.md).
- 캡처는 사용자가 직접 추가합니다. 각 기능 옆 상자에 준비 상태와 예정 파일명을 표시했습니다.

## 1. 데이터 불러오기

**용도:** 정렬에 사용할 점군·메시를 Align 세션에 추가합니다.

**위치:** **Data Layers → COLMAP 모델 불러오기 / OBJ 추가**.

### 입력 폴더와 연결 OBJ

다음과 같이 모델과 촬영 이미지를 함께 보관하는 구조를 사용합니다.

```text
scan_a/
├─ images/
│  ├─ image_001.jpg
│  └─ image_002.jpg
├─ sparse/
│  └─ 0/
│     ├─ cameras.bin
│     ├─ images.bin
│     └─ points3D.bin
└─ model.obj                 ← Align에서 연결할 메시가 있을 때
```

- `images/`: 실제 촬영 이미지입니다. COLMAP 모델에 기록된 이름과 일치해야 합니다.
- `sparse/0/`: 카메라·이미지 자세·희소 점군을 담는 COLMAP 모델입니다.
- TXT 입력에서는 `cameras.txt`, `images.txt`, `points3D.txt`를 사용합니다.
- `sparse/` 바로 아래에 모델 파일이 있는 단일 모델 구조도 지원합니다.
- 데이터에 `rigs`·`frames` 파일 등이 함께 있다면 임의로 제거하지 말고 그대로 보관합니다.

Align의 폴더 선택 창에서는 데이터셋 루트 또는 실제 sparse 모델 폴더를 선택할 수 있습니다. 하나의 데이터셋에 여러 sparse 모델이 있고 OBJ를 연결하려면, 연결 대상인 모델 폴더까지 명확히 선택하십시오.

<a id="capture-04"></a>

> **[캡처 04] 입력 폴더 구조**
>
> - 준비: 예시 데이터셋을 파일 탐색기에서 연 상태. 필요하면 sparse 폴더 내부 화면을 함께 배치.
> - 필수 표시: `images`와 `sparse`의 형제 관계, 모델 파일, 연결 OBJ 위치.
> - 예정 파일: `images/04-input-folder.png`

연결 OBJ는 **`images`·`sparse`와 같은 데이터셋 루트 바로 아래**에 둡니다. 하위 폴더의 OBJ는 자동으로 재귀 검색하지 않습니다.

| 루트의 OBJ 수 | 불러오기 동작 |
|---|---|
| 없음 | COLMAP만 불러옴 |
| 하나 | `OBJ 함께 불러오기`를 켰을 때 자동 연결 |
| 여러 개 | 연결할 OBJ 파일을 직접 지정 |

연결 OBJ와 COLMAP은 같은 모델을 표현해야 합니다. 내보내기 설정에 따라 표시 축은 다를 수 있지만, 두 파일의 원래 위치·단위·크기 관계가 맞아야 합니다. 축 설정만으로 별도로 이동하거나 크기가 달라진 메시까지 자동으로 맞춰 주지는 않습니다.

COLMAP 없이 메시끼리 정렬하려면 Align의 **OBJ 추가**를 사용합니다.

### COLMAP 모델 불러오기

**COLMAP 모델 불러오기**를 누르고 입력 폴더를 선택합니다.

| 항목 | 설정 방법 |
|---|---|
| Input Format | 일반적으로 `Auto`. 필요할 때 Binary 또는 TXT를 직접 선택 |
| OBJ 함께 불러오기 | 같은 데이터셋의 메시도 사용할 때 켬 |
| OBJ 파일 | 후보가 여러 개이면 연결할 파일 지정 |
| Point Limit | 화면에 표시할 희소 점 수의 상한 |
| Display Axis | 원본 좌표계에 맞는 표시 축 선택 |

**Point Limit는 화면 표시 설정**입니다. 새 정렬 엔진은 선택 형상의 전체 유효점을 사용합니다. 표시 점을 줄였다고 원본 COLMAP 파일에서 점을 지우는 것은 아닙니다.

COLMAP 없이 OBJ만 불러올 때는 **OBJ 추가**에서 파일을 선택합니다. 가져오기가 완료된 뒤 레이어 이름과 데이터가 보이는지 확인하십시오.

<a id="capture-06"></a>

> **[캡처 06] COLMAP 불러오기 옵션**
>
> - 준비: 입력 데이터셋을 선택한 파일 브라우저.
> - 필수 표시: 선택 폴더, Input Format, OBJ 함께 불러오기, Point Limit, Display Axis.
> - 예정 파일: `images/06-align-import-options.png`

### OBJ의 면·UV·텍스처

삼각형, 사각형, N곤 OBJ를 사용할 수 있습니다. Align 계산용 삼각화는 내부에서 수행하며 정상적으로 불러온 원본의 면 구성과 UV는 OBJ 내보내기에 보존됩니다. **원본 OBJ의 면 수를 50,000개로 제한하는 구조가 아닙니다.** 큰 모델은 메모리와 로딩 시간을 더 사용합니다.

새로 가져오는 OBJ는 **면에 사용되는 전체 정점을 마커 선택용으로 표시**하며 개수 제한을 두지 않습니다. COLMAP 점군의 `Point Limit`와는 별도이며 연결 OBJ에도 점군의 제한을 적용하지 않습니다. 기존 프로젝트의 독립 OBJ에 저장된 표시 상한은 유지되므로 이전에 가져온 모델에 적용하려면 OBJ를 다시 가져옵니다.

형상 정렬만 할 때는 텍스처가 필수는 아닙니다. 색상 표시나 텍스처가 있는 OBJ 출력을 원한다면 OBJ, MTL, MTL이 가리키는 이미지 경로를 함께 준비하십시오. 모든 종류의 MTL 확장·재질 노드를 그대로 왕복한다고 가정하지 않습니다.

**결과:** 입력마다 데이터 레이어가 만들어집니다. 연결 OBJ는 COLMAP과 한 레이어에서 관리하며 독립 OBJ는 별도 레이어가 됩니다. 불러온 뒤 [A/P 그룹](#layers)과 [축](#axes)을 확인합니다.

## 2. A/P 그룹과 레이어 관리

**용도:** 어떤 데이터를 기준으로 삼고 어떤 데이터를 움직일지 정합니다.

**위치:** **Data Layers**의 레이어 이름과 아이콘.

- **A**: 정렬의 기준으로 사용하는 그룹입니다.
- **P**: 현재 움직여 맞출 데이터입니다. 정밀 정렬은 선택한 P 하나를 대상으로 합니다.
- **Data Layers**: 불러온 데이터, A/P 소속, 표시할 형상과 축을 관리합니다.
- **Marker Align**: 대응점과 초기 정렬, 정밀 정렬 결과를 관리합니다.
- **Merge & Export**: 승인한 A 그룹의 결과를 내보냅니다.

처음 불러온 데이터는 기준 A로 등록되고 이후 데이터는 P로 추가됩니다. 레이어 이름을 한 번 클릭하면 선택합니다. 이름 더블클릭은 A/P 그룹 전환이며, 최초 기준 등 전환할 수 없는 상태는 안내에 따릅니다. 축 설정은 이름 더블클릭이 아닌 **톱니 아이콘**으로 엽니다.

> - 예정 파일: `images/05-align-overview.png`

### 표시할 형상과 정렬 입력 선택

COLMAP과 연결 OBJ는 하나의 레이어로 관리됩니다. 레이어의 점군·표면 아이콘 중 **하나만** 선택하여 표시하고, 그 형상을 정렬 입력으로 사용합니다.

| 레이어 조작 | 의미 |
|---|---|
| 점군 아이콘 | 희소 점군을 표시하고 점군을 정렬 입력으로 선택 |
| 표면 아이콘 | 메시를 표시하고 표면을 정렬 입력으로 선택 |
| 눈 아이콘 | 레이어 전체의 화면 표시를 켜거나 끔 |
| 톱니 아이콘 | 점군·카메라와 메시의 축 설정 |
| 이름 한 번 클릭 | 레이어 선택 |
| 이름 더블클릭 | 허용되는 상태에서 A/P 소속 전환 |

**A 그룹의 눈을 꺼도 그 데이터가 정렬 기준에서 제외되는 것은 아닙니다.** 기준에서 제외할 데이터는 A/P 소속을 확인해야 합니다. A 그룹 전체의 정렬 입력 종류도 맞춰야 하며, A 안에 점군·표면 종류가 섞이면 정렬을 시작할 수 없습니다.

`COLMAP RGB`는 점의 원래 색이나 지원되는 메시 텍스처 표시를 확인할 때 사용합니다. 표시 색 설정과 정렬 입력 종류는 별개입니다.

<a id="capture-07"></a>

> **[캡처 07] 레이어 아이콘**
>
> - 준비: COLMAP과 OBJ가 연결된 레이어가 보이는 상태.
> - 필수 표시: 레이어 이름, A/P 구분, 점군·표면·톱니·눈 아이콘. 한 레이어에서 두 형상이 동시에 선택된 화면을 만들지 않음.
> - 예정 파일: `images/07-align-layer-icons.png`

**결과:** 선택한 P 하나를 A 그룹에 맞춰 정렬합니다. 점군·표면 아이콘은 입력 종류를, 눈 아이콘은 화면 표시를 정합니다.

## 3. 데이터셋 축 설정

**용도:** COLMAP 점군·카메라와 연결 OBJ의 원본 축을 각각 보정하고, 데이터셋 이동·회전·배율을 함께 조절합니다.

**위치:** 해당 레이어의 **톱니 아이콘**.

COLMAP과 OBJ의 원본 위치가 같아도 가져오는 좌표계에 따라 한쪽이 누워 보일 수 있습니다.

1. 해당 레이어의 **톱니 아이콘**을 누릅니다.
2. 레이어에 COLMAP과 OBJ가 있으면 둘 다 표시됩니다. 한 종류만 있으면 그것만 표시됩니다.
3. 각 형상의 원본 형식에 맞는 프리셋과 Forward·Up을 선택합니다. 아래 **데이터셋 공통 변환**에서 XYZ 이동·회전·스케일을 함께 조정합니다.
4. **미리보기**로 위치와 방향을 확인합니다.
5. 맞으면 **적용**, 맞지 않으면 **취소**합니다.

회전과 스케일은 존재하는 두 형상의 **전체 바운딩 박스 중심**을 기준으로 적용됩니다. 이동값은 정렬 전 표시 축 기준입니다. **중심을 원점으로**를 누르면 기존 정렬까지 반영하여 데이터셋 전체 중심이 월드 원점 `(0, 0, 0)`으로 이동합니다.

기즈모를 기준으로 조절할 때는 다음 두 버튼을 사용합니다.

- **기즈모를 바운딩 박스 중심으로**: 물체는 그대로 두고 기즈모 중심만 현재 표시된 데이터셋의 전체 바운딩 박스 중심에 즉시 지정합니다.
- **물체를 이동해 기즈모를 원점으로**: 더블클릭 등으로 지정한 현재 기즈모가 월드 원점에 오도록 물체를 즉시 평행이동합니다. 중심 지정 버튼을 먼저 누를 필요는 없습니다. COLMAP과 연결 OBJ는 함께 이동합니다. 다른 레이어를 함께 선택했더라도 이동 대상은 이 팝업의 데이터셋 하나입니다.

0.3.81부터 두 버튼은 각각 **클릭 즉시 확정**됩니다. 팝업의 **취소·Esc로 되돌아가지 않으며**, 팝업을 닫은 뒤 **Ctrl+Z**로 각 동작을 한 단계씩 실행 취소할 수 있습니다. 팝업 중에도 기즈모 위치를 표시하지만 드래그는 잠깁니다. 기즈모 중심만 바꾸면 기존 정렬 품질은 유지됩니다. 사용자 기즈모 중심은 기존과 같이 현재 세션에서만 유지되며, 물체의 이동은 프로젝트 저장에 포함됩니다.

아직 적용하지 않은 축·회전·배율 입력은 두 버튼과 별도로 유지됩니다. 버튼은 미리보기 켜짐·꺼짐에 따라 **현재 보이는 배치**를 기준으로 동작합니다. 이후 미적용 입력을 취소하면 그 입력에 의한 배치만 복원되므로, 물체에 붙은 기즈모의 화면 위치도 달라질 수 있습니다.

형상별 **RC 축 초기화**는 해당 원본 축만 초기화합니다. **변환 초기화**는 공통 이동·회전을 0, 스케일을 1로 초기화합니다. 기존 프로젝트에서 각각 조절한 형상의 배치는 보존됩니다.

스케일은 X·Y·Z를 각각 조절할 수 있습니다. **자물쇠를 잠그면 현재 X:Y:Z 비율을 유지**하면서 한 축의 변화 비율을 나머지 축에도 적용합니다. 예를 들어 `(2, 3, 4)`에서 잠근 뒤 Y를 6으로 바꾸면 `(4, 6, 8)`이 됩니다. 잠금만 켜거나 끌 때 값은 변하지 않습니다.

이동·회전·스케일 입력은 미리보기 후 적용하며, 취소하면 미적용 입력만 이전 상태로 돌아갑니다. 팝업 중 동시 표시는 기존 눈 상태와 점군·표면 선택을 바꾸지 않으며, 팝업을 닫으면 원래 표시로 돌아갑니다. 적용한 이동·회전·스케일은 되돌리기·다시 실행과 프로젝트 저장·복원을 지원합니다. COLMAP 카메라를 내보낼 때에는 세 축의 배율이 같아야 합니다. OBJ는 축별 배율을 반영하여 내보낼 수 있습니다.

RC 입력의 기본값은 다음과 같습니다. 다른 프로그램이나 RC 사용자 설정으로 내보낸 파일은 실제 축을 먼저 확인하십시오.

| 입력 | 기본 프리셋 | Forward | Up |
|---|---|---|---|
| RC COLMAP | RC COLMAP | `Z` | `-Y` |
| RC 표준 OBJ | RC 표준 OBJ | `Y` | `Z` |

축을 바꾸면 그 축을 사용한 기존 정렬 품질 기록이 무효가 될 수 있습니다. **축 확인을 끝낸 다음 마커 지정과 정렬을 시작**하는 순서가 좋습니다. 축 변경은 원본 파일을 직접 고치는 작업이 아닙니다.

## 4. 마커 쌍 관리

**용도:** A와 P에서 같은 부위의 대응점을 지정하고 수정합니다.

**위치:** **Marker Align → 마커 쌍 추가 / 쌍 지정 / 마커 편집 / 선택 쌍 삭제**.

1. 기준 A와 움직일 P를 확인합니다.
2. 각각 마커를 찍을 점군 또는 메시를 선택합니다.
3. **마커 쌍 추가**를 누릅니다.
4. A 화면과 P 화면에서 실제로 같은 부위를 한 곳씩 클릭합니다.
5. 두 후보 위치를 확인하고 **쌍 지정**으로 확정합니다.
6. 같은 방식으로 총 세 쌍을 만듭니다.

세 점은 한곳에 몰리지 않게, 가능한 한 넓고 서로 다른 높이·방향에 배치합니다. 거의 일직선인 세 점, 반복 무늬 때문에 구별하기 어려운 곳, 양쪽에 공통으로 없는 돌출부는 피합니다.

모든 쌍에서 **A끼리는 같은 형상 종류**, **P끼리도 같은 형상 종류**를 사용해야 합니다. A가 메시이고 P가 점군인 조합은 가능합니다. A1은 메시, A2는 점군처럼 역할 안에서 종류를 바꾸면 안내 후 차단됩니다. 종류를 바꾸려면 기존 쌍을 정리하고 다시 지정합니다.

현재 후보를 잘못 골랐다면 확정 전에 다시 선택합니다. 입력을 그만두려면 N 패널의 **선택 취소**를 사용합니다. 마커 입력 종료를 Esc나 오른쪽 클릭에만 의존하지 마십시오. 확정한 쌍은 목록에서 선택한 뒤 **마커 편집** 또는 **선택 쌍 삭제**로 수정합니다.

메시 마커를 추가하거나 편집할 때는 메시 표면과 지정한 마커가 표시되며, 메시 정점을 점으로 겹쳐 표시하지 않습니다. COLMAP 점군의 점 표시는 그대로 유지됩니다.

**되돌리기 / 다시 실행**으로 마커 편집 이력을 이동할 수 있습니다. 마커 입력 중에는 현재 입력 단계의 이력을 사용합니다. 버튼이 비활성이라면 되돌릴 이력이 있는지, 정렬 미리보기나 다른 작업이 진행 중인지 확인합니다.

역할별 입력 형상 고정·충돌·숨김 안내, 편집 중인 마커 번호와 목록 편집·삭제 잠금 안내는 버튼 아래 **상태 로그** 영역에 표시됩니다. 마커 입력 전후 조작 버튼의 행 수를 유지하여 안내 문구 때문에 버튼 위치가 밀리지 않도록 합니다.

## 5. 3점 마커 정렬

**용도:** 멀리 떨어지거나 회전·크기가 다른 데이터를 정밀 정렬을 시작할 수 있는 배치로 맞춥니다.

**위치:** **Marker Align → 3점 마커 정렬**, **Marker Refine Scale**.

1. 세 쌍을 준비하고, 크기까지 맞춰야 한다면 **Marker Refine Scale**을 켭니다.
2. **3점 마커 정렬**을 누릅니다.
3. P의 전체 방향·위치·크기가 A와 맞는지 확인합니다.
4. 엉뚱한 방향으로 이동했다면 미리보기를 해제하고 대응점을 수정합니다.

Marker Refine Scale을 바꾸려면 미리보기를 해제한 뒤 옵션을 변경하고 다시 정렬합니다.

3점 정렬은 정밀 정렬이 시작할 위치를 잡는 단계입니다. 이 미리보기만 보고 파일 내보내기가 완료되었다고 판단하지 마십시오. 연결된 COLMAP·카메라·메시는 레이어의 같은 정렬 변환을 따릅니다.

미리보기에서는 **A·P 양쪽 뷰포트에 기준 A와 정렬된 P를 함께 표시**합니다. 점군과 메시는 일반 표시를 유지하며 세 점을 잇는 A·P 대표 삼각형만 양쪽에 반투명하게 표시됩니다. 각 뷰의 시점은 유지되며 미리보기를 취소하면 원래 역할별 표시로 돌아갑니다.

## 6. 점 기반 정밀 정렬

**용도:** 겹치는 영역의 위치·회전을 세밀하게 맞춥니다. **배율 함께 보정 (Sim(3))**을 켜면 균일 배율도 함께 맞춥니다.

**위치:** **Marker Align → Align**.

초기 배치가 맞으면 **Align**을 누릅니다. 이미 두 데이터가 충분히 가까운 경우에는 마커 미리보기 없이 현재 P 위치에서 직접 시작할 수도 있습니다.

정렬 방식은 선택한 입력으로 자동 결정됩니다.

| 이동 P | 기준 A | 사용할 입력 |
|---|---|---|
| 점군 | 점군 | 최근접 원본점 사이의 점–점 강체 정렬 |
| 점군 | 메시 | 점군과 메시 정점의 접평면 사이의 점–평면 정렬 |
| 메시 | 점군 | 점군→메시로 계산한 뒤 역행렬을 이동 P에 적용 |
| 메시 | 메시 | 작은 메시를 질의하는 정점 접평면 정렬 |

선택한 형상의 전체 유효점을 유지하고 검색 대상의 KD-tree를 작업당 한 번 만듭니다. 대응 거리와 필요한 법선 조건을 검사한 뒤 먼 대응 5%를 계산 가중치에서 제외합니다. 메시 간소화나 50,000점 표면 표본 생성은 수행하지 않습니다. 한 번의 정렬에서 변환 갱신은 최대 30회입니다.

현재 수렴은 **목적함수 RMS의 상대 변화가 0.001 미만**, 또는 **이동·회전 갱신 벡터의 상대 변화가 모두 0.001 미만**일 때 표시합니다. 상대 변화는 직전 값과의 차이를 직전 값의 크기 + `1e-9`로 나눕니다. 회전은 축×라디안각 벡터이며 이동·회전은 누적 변환이 아닌 한 번의 갱신값입니다. 첫 벡터 이력은 영이고 대응 수 일치 조건은 없습니다. 실제 기본 허용치는 Artec에서 확인한 단정도 0.001의 배정도 값입니다. 최대 30회, 대응 급감·목적함수 악화의 별도 검토 분기는 유지합니다.

정점이 겹치거나 면적이 없어 계산할 수 없는 퇴화 삼각면은 정렬 계산에서만 제외합니다. 원본 메시·UV·마커 번호와 저장·내보내기에 사용하는 원본 면은 유지됩니다. 남은 유효면이 없거나 유효 대응 수와 강체 계산의 구속 조건을 충족하지 못하면 정렬을 중단합니다.

기본은 **배율 함께 보정 (Sim(3)) 꺼짐**이며 현재 배율을 유지합니다. 크기 차이도 정밀 정렬로 줄이려면 Marker Align 영역의 **배율 함께 보정 (Sim(3))**을 켠 뒤 Align을 누릅니다. 이 옵션은 **Marker Refine Scale**과 별개이며 3점 마커로 생긴 배율 오차도 표면·점군 대응으로 보정합니다. 결과에는 실제 추가 배율이 표시되고, 정렬 승인 전에는 미리보기만 적용됩니다. 원본 정점·면·UV는 변경하지 않습니다. 대응 영역이 부족하거나 배율을 결정할 형상 정보가 부족하면 계산이 실패하거나 결과 검토가 필요할 수 있습니다.

정점의 접평면은 삼각형 내부의 정확한 표면점과 다릅니다. 특히 성긴 메시와 고밀도 점군 사이에서는 근사 오차가 생길 수 있으므로 공통 부위를 확인하십시오. 독립 표면 오차 평가·GPU 정렬은 포함하지 않습니다. Sim(3) 역시 전체 모델에 공통인 균일 배율만 보정하며 국소 변형이나 축별 크기 차이를 보정하지 않습니다.

진행 중 그만두려면 **ICP 취소**를 사용하고 취소 처리가 완료될 때까지 기다립니다.

**사용 조건:** 기준 A와 선택한 P가 있어야 하고, A 그룹의 입력 종류가 일치해야 합니다. 초기 배치가 충분히 가까워야 공통 영역을 찾을 수 있습니다.

**결과:** 계산된 변환은 결과 미리보기로 표시됩니다. [정렬 승인](#review)을 눌러야 결과가 확정됩니다.

## 7. 결과 검토·승인·버리기

**용도:** 정렬 품질을 확인하고 결과를 적용할지 결정합니다.

**위치:** **Marker Align**의 상태 로그와 **정렬 승인 / 결과 버리기**.

정렬이 끝나면 상태 로그와 화면을 함께 확인합니다.

| 표시 | 읽는 방법 |
|---|---|
| 정렬 대응 RMS | 마지막 계산에 사용한 대응점들의 유클리드 거리 오차. 독립 표면 정확도와 다름 |
| 유효 대응 수 | 실제로 비교할 수 있는 대응의 양. 오차 숫자와 함께 확인 |
| 변환 갱신 횟수·종료 사유 | 수렴, 최대 30회 도달, 목적함수 악화 등을 구분 |
| 독립 겹침 평가 미실시 | 기존 CC의 겹침 평가 RMS를 계산하지 않았다는 표시 |
| REVIEW | 결과는 계산되었지만 사용자가 검토할 사유가 있다는 표시 |

RMS는 모델 좌표의 길이 단위를 따릅니다. 데이터가 미터 기준인지, 임의 스케일인지 모르는 상태에서 숫자를 mm로 해석하면 안 됩니다.

과거 CC 정렬 기록의 겹침 평가 RMS·개선율은 당시 평가 방식의 값으로 유지합니다. 새 엔진의 정렬 대응 RMS와 같은 지표로 직접 비교하지 마십시오. 최대 반복에 도달한 결과는 수렴 성공으로 표시하지 않습니다.

1. 공통 표면의 가장자리, 뚜렷한 특징, 서로 떨어진 여러 부위를 확인합니다.
2. 숫자가 좋아져도 형상이 일부 틀어지거나 실제 크기가 부자연스럽다면 승인하지 않습니다.
3. 결과가 적절하면 **정렬 승인**을 누릅니다. 확정한 P는 A 그룹으로 편입됩니다.
4. 적절하지 않으면 **결과 버리기**로 돌아가 마커·입력 종류·초기 위치를 수정합니다.

정렬 승인과 `.blend` 저장, 외부 파일 내보내기는 별도입니다. RC에서 다시 재구성할 데이터라면 내보낸 뒤 RC 결과도 확인하십시오. 서로 다른 재구성에서 생긴 국소 변형까지 하나의 위치·회전·균일 배율 변환으로 모두 없앨 수는 없습니다.

> - 필수 표시: 정렬 대응 RMS·대응 수·갱신 횟수·종료 사유·독립 평가 미실시, 정렬 승인·결과 버리기.

## 8. COLMAP Export

**용도:** 승인된 A 그룹을 합친 새 COLMAP 데이터셋을 만듭니다.

**위치:** **Merge & Export → COLMAP Export**.

1. 출력할 데이터가 **A 그룹**에 있는지 확인합니다. P에 남아 있는 데이터는 승인 여부를 확인합니다.
2. **Merge & Export → COLMAP Export**를 누릅니다.
3. 출력의 부모 폴더를 선택합니다. 입력 데이터셋 내부에 출력 폴더를 두지 않습니다.
4. **Sparse Format**에서 TXT 또는 Binary를 선택합니다.
5. 원래 COLMAP 좌표계로 넘기려면 **Import 축변환 되돌리기**를 켭니다. 기준 Anchor의 원래 축을 기준으로 출력됩니다.
6. 완료 안내와 실제 결과 폴더를 확인합니다.

선택한 부모 폴더 아래에 **`colmap_merged/`**가 만들어집니다. 같은 결과 폴더가 이미 있으면 덮어쓰기 확인 내용을 읽으십시오. 완료 후 `images/`와 `sparse/0/`의 모델 파일이 있는지 확인합니다.

**출력 범위:** A 그룹에 포함된 COLMAP 데이터입니다. 눈을 꺼 숨긴 A도 출력 대상이 될 수 있습니다. 독립 OBJ만 있는 레이어에서 COLMAP 카메라를 새로 만들지는 않습니다.

Modifier에서 결과를 편집하려면 생성된 `colmap_merged/`를 [Modifier의 Import](MODIFIER.md#import)로 불러옵니다.

> **[캡처 12] Align 내보내기**

> - 준비: 출력 대상이 A에 등록되어 있고 COLMAP 출력 파일 브라우저가 열린 상태. 완료 폴더는 보조 컷으로 추가 가능.
> - 필수 표시: Sparse Format, Import 축변환 되돌리기, COLMAP Export·OBJ Export 위치, `colmap_merged`·`aligned_obj` 결과 이름.

## 9. OBJ Export

**용도:** 확정한 변환을 적용한 메시를 다른 프로그램에서 사용합니다.

**위치:** **Merge & Export → OBJ Export**.

1. 출력할 폴리곤 레이어가 A 그룹에 있는지 확인합니다.
2. **OBJ Export**를 누르고 부모 폴더를 선택합니다.
3. 완료 후 **`aligned_obj/`**를 확인합니다.

원본 면 구성과 UV에 확정 변환을 적용한 레이어별 OBJ가 출력됩니다. 지원되는 diffuse 텍스처가 있으면 MTL과 이미지도 함께 전달됩니다. 이름 충돌이나 외부 이미지 누락 안내가 있다면 해결한 뒤 다시 출력합니다.

**OBJ는 Align 작업공간 좌표(Project World)로 출력됩니다.** COLMAP의 `Import 축변환 되돌리기` 옵션과 같은 출력 축이라고 가정하지 마십시오. 두 결과를 외부 프로그램에서 함께 사용할 때는 그 프로그램의 입력 축도 확인합니다.

**원본 보존:** 정상 내장된 OBJ의 삼각형·사각형·N곤과 UV를 유지합니다. 계산에 사용한 삼각형 데이터로 원본 면 구성을 바꾸어 출력하지 않습니다. COLMAP 출력과 OBJ 출력은 각각 실행합니다.

Projection Paint에서 사용하려면 내보낸 OBJ를 일반 Blender Mesh로 다시 불러와 [페인트 대상](PROJECTION_PAINT.md#paint-target)으로 지정합니다.

<a id="viewport"></a>

## 10. 화면 표시 설정

**용도:** 데이터를 읽기 쉽게 표시하고 수동 배치 도구를 켜거나 끕니다.

**위치:** **Viewport** 패널.

| 항목 | 기능 |
|---|---|
| 포인트 크기 | 화면에 그리는 희소 점 크기를 조절 |
| 기즈모 표시 | 선택 레이어의 이동·회전·스케일 기즈모 표시 전환 |
| COLMAP RGB | 점군의 원본 RGB, UV와 diffuse 이미지가 있는 OBJ의 원본 텍스처 표시 |

표시 색상이나 점 크기를 조절해도 원본 점 개수나 정렬 입력 종류는 바뀌지 않습니다. 정렬 입력을 바꾸려면 [레이어의 점군·표면 아이콘](#layers)을 사용합니다.

새 Align 작업공간은 왼쪽 A, 오른쪽 P로 나뉘며 오른쪽 N 패널이 기본으로 열립니다. 패널이 닫혀 있으면 해당 화면의 **View → Sidebar**를 사용합니다. 화면 탐색은 [공통 조작](README.md#navigation)을 참고하십시오.

두 뷰의 바닥에는 원점 기준 +X·+Y 방향으로 **1 m~10 m** 눈금이 표시됩니다. 데이터의 이동·회전·배율이나 피벗을 바꿔도 눈금은 같은 월드 위치를 유지합니다. 확대·축소하면 표시 위치가 함께 움직이며, 너무 가까워 겹치는 글자는 일부 생략합니다. Blender의 **오버레이 표시**를 끄면 눈금도 숨겨집니다.

Scene 단위가 없음이면 1 Blender 단위를 1m로 표시하고, Metric·Imperial이면 Scene의 단위 배율을 반영합니다. 실제 물체 크기를 자동으로 보정하는 기능은 아니므로 알려진 길이에 맞춰 데이터 배율을 조절해야 합니다.

## 11. CPU와 정렬 환경 설정

**용도:** 점 기반 정렬 실행 환경을 확인하고 다른 작업과 함께 사용할 CPU 상한을 정합니다.

**위치:** **Edit → Preferences → Add-ons → COLMAP Tools**.

Preferences의 Add-ons 목록에서 **COLMAP Tools** 항목을 펼칩니다.

1. **점 기반 정렬 환경 검사**를 누릅니다.
2. 검사 결과를 확인합니다. 실패했다면 새 정렬을 시작하기 전에 설치 파일과 재시작 여부를 확인합니다.
3. 필요하면 **CPU 스레드**를 설정합니다.

| CPU 스레드 값 | 의미 |
|---|---|
| `0` | 자동. 사용 가능한 논리 CPU 수에서 하나를 남기는 정책 |
| `1` | 단일 스레드 |
| `2` 이상 | 사용할 최대 스레드 수. 실제 CPU 수를 넘으면 제한됨 |

변경값은 **다음 정렬 작업부터** 적용됩니다. 다른 작업과 함께 사용할 때는 더 낮은 상한을 지정할 수 있습니다. 현재 정렬은 CPU를 사용하며 GPU 정렬 옵션은 없습니다.

최근접점 검색과 작은 행렬의 누적 계산은 CPU 병렬 처리를 사용합니다. KD-tree 생성과 일부 전처리에는 병렬화되지 않은 구간이 있어 스레드 수에 비례해 전체 시간이 줄지는 않습니다.

> - 필수 표시: 확장 이름·버전, `CPU 스레드`, `점 기반 정렬 환경 검사`.

## 12. 저장·세션 복원

**용도:** 레이어·마커·확정 변환을 보관하고 같은 작업을 이어갑니다.

**위치:** Blender **File → Save / Save As**, **COLMAP Align** 작업공간.

1. 정렬 승인 등 진행 중인 작업을 완료합니다.
2. `.blend`를 저장합니다. COLMAP·OBJ 파일이 필요하면 각 Export도 별도로 실행합니다.
3. 다시 열고 데이터 복원·세션 연결이 끝날 때까지 기다립니다.
4. 레이어·마커·확정 상태를 확인합니다.

| 저장 범위 | 내용 |
|---|---|
| `.blend`에 저장 | 레이어, 축, 마커, 확정 변환, 정렬 기록, 정상 내장된 OBJ 원본 면·UV |
| 외부 파일 보관 필요 | COLMAP 원본 모델, 관련 촬영 이미지, 외부 텍스처 |

Align 작업공간에서 저장했다면 복원 후 세션이 자동 연결됩니다. 일반 작업공간에서 저장했다면 그 화면을 유지하며 Align 탭으로 이동할 때 세션을 사용합니다. 다른 작업공간으로 이동해도 Align 데이터가 삭제되는 것은 아닙니다.

원본 누락 안내와 함께 **원본 다시 연결 / 재시도**가 나오면 같은 원본을 연결하십시오. OBJ 형상 내장과 이미지 파일 보관은 별개이므로 다른 컴퓨터로 옮길 때는 COLMAP과 촬영 이미지·외부 텍스처도 함께 전달합니다.

> - 준비: 저장했던 Align 프로젝트를 다시 열고 연결·복원이 완료된 상태.
> - 필수 표시: 복원된 레이어·마커 또는 승인 상태, 정상 사용 가능한 패널. 복원 오류 안내는 별도 보조 컷으로 분리.

## 13. 문제 해결·입력 참고

| 증상 | 확인할 기능 |
|---|---|
| 연결 OBJ가 안 보임 | [입력 폴더](#import)의 OBJ 위치, OBJ 함께 불러오기, 다중 후보 선택 |
| 점군 또는 메시만 보임 | [레이어 입력 선택](#layers)은 한 종류만 표시함. 눈 상태도 확인 |
| 점군과 메시가 90도 틀어짐 | [데이터셋 축 설정](#axes)의 COLMAP·OBJ 프리셋과 실제 원본 축 |
| 마커 입력 종류 변경이 막힘 | [마커 쌍](#markers)은 A끼리·P끼리 종류가 고정됨 |
| 마커 입력을 끝낼 수 없음 | 후보를 정한 뒤 쌍 지정, 중단하려면 선택 취소 |
| Align 버튼이 비활성 | 선택 P, 기준 A, A의 입력 종류 일치, 다른 작업 진행 여부 |
| 겹침 후보가 부족함 | [3점 정렬](#marker-align)의 대응점과 실제 공통 영역 |
| 대응 RMS가 작아도 일부가 어긋남 | [정렬 대응 RMS의 한계](#review)를 확인하고 여러 공통 부위를 직접 비교 |
| RC 결과가 여전히 어긋남 | 출력 축·배율, 공통 표면, 재구성마다 다른 국소 형상 확인 |
| A를 숨겼는데 정렬·출력에 사용됨 | 눈은 표시 설정. [A/P 그룹](#layers) 구성을 확인 |
| Export 대상이 없다는 안내 | A 그룹에 해당 종류의 데이터가 있는지 확인 |
| 실행 환경 오류 | [점 기반 정렬 환경 검사](#cpu), 정식 ZIP 설치와 재시작 확인 |
| 저장 파일 복원이 안 됨 | [외부 원본 보관·재연결](#save) 확인 |

| 입력 | 동작 |
|---|---|
| 레이어 이름 한 번 클릭 | 레이어 선택 |
| 레이어 이름 더블클릭 | 허용되는 상태에서 A/P 전환 |
| 레이어 톱니 | 데이터셋 축 설정 |
| 쌍 지정 / 선택 취소 | 마커 후보 확정 / 입력 취소 |
| ICP 취소 | 실행 중인 정밀 정렬 취소 요청 |
