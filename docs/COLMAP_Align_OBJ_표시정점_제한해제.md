# Align OBJ 표시 정점 제한 해제

## 범위와 계약

`codex/artec-align-engine`에서 새 OBJ 가져오기의 마커 표시 정점 기본 상한 250,000개를 해제한다. 원본 정점·면 및 정렬 입력은 이미 전체 형상을 사용하므로 이 변경은 표시 정점 선택에만 적용된다.

- 기본값 `None`은 제한 없음을 뜻한다. 메시를 읽은 뒤 면에 사용되는 전체 등록 정점 개수로 확정한다.
- API에서 명시한 양의 정수 제한은 유지한다. 잘못된 값 거절과 취소·실패 정리도 유지한다.
- 독립 OBJ는 확정한 개수를 기존 양의 정수 메타데이터로 저장한다. 저장 형식은 바꾸지 않으며 기존 프로젝트에 저장된 명시적 표시 상한을 존중한다.
- COLMAP의 `Point Limit` 기본값과 점군 표시는 유지한다. 연결 OBJ는 전체 정점을 사용하며, 복원 때 부모 COLMAP의 점군 제한을 연결 메시로 전달하지 않는다.
- OBJ 가져오기 안내를 전체 정점 사용으로 변경한다. 원본 좌표·면·UV·재질과 마커 화면 ID 경로는 유지한다.

## 검증

2026-10-21, 블렌더 5.2.0 LTS에서 다음 검사를 통과했다.

- 정점 250,002개·삼각형 83,334개의 실제 OBJ를 기본 설정으로 가져와 표시 정점 250,002개를 확인했다. 저장 상태의 직렬화·복호화 및 내장 메시 복원 후에도 정점·삼각형·표시 인덱스가 일치했다.
- 같은 OBJ에 명시적 제한 7개를 지정하면 표시만 7개로 유지되며 원본 정점은 250,002개를 보존했다. 저장·복원 후에도 동일했다.
- 부모 COLMAP 점군의 표시 제한이 1개여도 연결 OBJ의 정점 3개를 전부 표시하고 복원했다.
- 0·음수·참/거짓·실수·문자열 형태의 잘못된 명시적 제한은 계속 거절했다.
- 필수 Align 소스 회귀 스크립트 48개와 별도의 점군 표시 표본 검사를 통과했다.
- 설치본에서도 새 OBJ 가져오기·저장·복원 검사 3개와 확장 등록·해제 검사를 통과했다.

검증 로그와 설치 전 백업·파일 해시는 `build/verification/obj-display-unlimited-20261021/`에 보관했다. 성능이나 GPU 메모리 사용량을 새로 측정한 결과는 아니다.

## 설치와 적용

블렌더 5.2의 `user_default/colmap_tools` 설치 경로에 변경한 실행 파일 4개만 반영했고 소스와 해시 일치를 확인했다. 실행 중인 블렌더 세션은 다시 불러오지 않았다. 블렌더를 재시작한 뒤 OBJ를 새로 가져오면 적용된다. 기존 독립 OBJ의 저장된 제한을 해제하려면 해당 OBJ를 다시 가져온다.
