# 데이터셋 축 설정의 이동·배율·중심 변환

- 요청: XYZ 이동·회전·배율, 바운딩 박스 중심 회전, 중심을 월드 원점으로 이동, 자물쇠로 현재 XYZ 배율 비율 유지.
- 범위: Align의 표시 변환·편집 팝업·저장·정렬 입력. 원본 정점과 원본 파일, 공통 정렬 행렬은 보존한다.

## 구현 구조

1. 표시 변환에 이동 `t`, 양수 배율 `s`, 원본 중심 `c`를 추가한다. 원본 축 변환 `B`, 추가 회전 `R`에 대해 `N(x) = R diag(s) B(x-c) + Bc + t`로 계산한다. 이동은 정렬 전 표시 축 기준이다.
2. 중심은 기존 원본 경계 상자의 최소·최대 중간점이다. 원본 전체 순회 없이 현재 표시 경계 상자의 중심을 유지한다. 팝업을 열 때 기존 회전의 위치를 보정하고, 수정하지 않은 값은 원래 float64 값을 유지한다.
3. 각 형상의 배율 잠금은 기본 해제다. 잠금 자체로 값이 바뀌지 않으며, 한 축의 편집 비율을 나머지 축에도 곱한다. 지원 배율 범위는 0.000001–1000000이다.
4. 원점 이동은 기존 공통 정렬 `C`의 역변환을 적용해 `C N(c) = (0,0,0)`을 만족한다. 미리보기만 갱신하고 적용할 때 기존 단일 Undo 경계로 확정한다.
5. 프로젝트 저장 버전 9에 세 필드를 추가한다. 버전 1–8은 이동 0·배율 1·중심 0으로 읽어 기존 행렬과 지문을 유지한다. 새 변환을 구버전으로 손실 저장하지 않는다.
6. ICP의 표시 변환은 양수 배율의 가역 아핀 행렬을 허용한다. ICP가 계산하는 공통 정렬 자체는 기존 Sim(3) 제약을 유지한다. OBJ는 변환된 형상을 출력한다. COLMAP 카메라 내보내기는 기존 균일 배율 조건을 유지하고 팝업에 필요한 안내를 표시한다.

## 검증 기준

- 중심 고정 회전·비균일 배율, 정렬 후 월드 원점 이동.
- 잠금·해제·축별 편집 및 값 경계, 주 형상과 연결 메시의 독립성.
- 팝업 무변경 적용과 취소, 단일 Undo/Redo, 원본 배열 보존.
- 저장 왕복의 행렬·지문 일치와 구버전 읽기, 잘못된 배율 거부.
- ICP 입력 좌표 및 OBJ 출력 행렬, 기존 축 설정·등록·저장 회귀.

Blender 속성은 [공식 속성 API](https://docs.blender.org/api/main/bpy.props.html)의 벡터 속성과 갱신 콜백을 사용한다. 메시 음영은 기존 역전치 노말 행렬을 유지한다.

## 구현·검증 결과

- 0.3.71에 구현했다. Blender의 RNA 속성 갱신에서도 동일한 편집 토큰으로 비율 기준을 공유하고, 팝업 종료 시 함께 해제한다.
- Align 필수 소스 검사 44개 파일을 통과했다. 새 변환 검사에는 중심 고정, 비율 잠금·해제, 원점 이동, 취소·무변경 적용, Undo/Redo, 실제 저장·복원, ICP 입력, 작은 배율 및 큰 좌표를 포함했다.
- 별도 Blender 5.2 창에서 실제 RNA 한 축 편집, 잠금, 원점 이동, 초기화, Esc, 적용, 작업공간 이탈을 검증했다. 주 형상·연결 메시 및 독립 OBJ 팝업 화면도 확인했다.
- 정식 빌드의 통합 등록·해제와 실제 정렬 검사, ZIP 격리 설치의 정렬·환경설정·OBJ 입출력 검사를 통과했다.
- 추가 실행한 과거 `test_registration.py` 전체 검사는 여전히 `SMALL_GICP`를 기본 엔진으로 기대하는 기존 항목에서 실패했다. 현재 기본 엔진은 CCCoreLib이며 이번 범위에서 엔진 또는 해당 과거 기댓값은 변경하지 않았다. 정식 통합 등록·해제 검사는 통과했다.
- 검증 결과는 `build/verification/axis-transform-20260921/`에 저장했다. 패키지 SHA-256은 `5ada3c87be2951e88cefdbd7d341d2ff17a4e498564db964d87ad45dd415df10`이다.
- 실제 설치본을 백업하고 변경된 11개 파일을 교체했다. 배포 파일 1,185개의 패키지 일치와 환경설정 보존을 확인했다. 열린 `Untitled.blend`에는 저장하지 않은 변경이 있어 실행 중인 세션은 유지했다. 저장 후 Blender를 재시작하면 0.3.71이 로드된다.
