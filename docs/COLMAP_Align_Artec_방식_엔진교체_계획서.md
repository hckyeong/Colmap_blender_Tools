# COLMAP Align: Artec 관측 흐름을 기준으로 한 정렬 엔진 교체 계획

- 작성일: 2026-10-21
- 상태: **1차 구현 및 지정된 두 실제 메시 검증 완료**. 조밀한 점군–성긴 메시 정밀도 목표는 미달이며 운영 배포 전환은 보류한다. 구현과 원래 계획의 차이·실측·제한은 [구현 검증 보고서](COLMAP_Align_Artec_방식_엔진교체_구현검증.md)에 기록한다.
- 작업 브랜치: `codex/artec-align-engine`
- 분기 기준: `main`, `48afa7d6a3bc939194208b3b7d544d46d1ef7e18`
- 비교 기준: 설치본 COLMAP Tools 0.3.75, Blender 5.2.0 LTS, Artec Studio 16 Professional 16.0.8.2
- 작업 시작 시 존재한 미커밋 변경은 보존한다. 기준 커밋만으로 현재 작업 트리 전체를 재현할 수 없으므로, 구현 착수 시 관련 소스의 지문과 변경 상태도 함께 기록한다.

## 1. 목표와 범위

기본 Align을 **원본 유효점 → KD-tree 대응점 검색 → 대응점 필터 → 강체 ICP → 수렴 판정** 경로로 교체한다. 현재의 표면 표본 생성, 삼각형 BVH 검색, 추가 배율 최적화, 독립 평가에 의한 후보 선택은 새 기본 경로에서 제외한다.

점군–점군, 점군–메시, 메시–메시 정렬은 모두 1차 구현에 포함한다. 메시와 점군이라는 **입력 종류**와 점–점·점–평면이라는 **최적화 오차 방식**을 구분한다. 법선이 없는 COLMAP 점군끼리도 점–점 강체 정렬로 지원한다.

Artec에서 확인한 실행 구조를 참고해 독립적인 엔진을 구현한다. Artec의 미확인 수식·분기까지 동일하게 복제한다고 전제하지 않는다. 이하의 관측값과 제품 설계 결정은 구분해서 읽는다.

### 1.1 1차에 유지할 기능

- 현재 위치 또는 기존 마커 정렬을 시작 위치로 사용한다.
- 기준 A 그룹과 이동 P 하나의 역할, 숨김과 정렬 대상의 구분, A 그룹 입력 종류 검사 규칙을 유지한다.
- 정렬 결과 미리보기, 승인, 버리기, 취소, Undo/Redo, 저장·복원과 내보내기를 유지한다.
- 기존 마커 배율과 사용자가 설정한 크기는 유지한다. 새 ICP는 그 상태에서 회전·이동만 추가한다.
- COLMAP 점군·카메라·연결 OBJ에 같은 공통 정렬 변환을 적용한다.
- 원본 정점·점 ID·면·UV·재질·텍스처를 보존한다. 계산용 유효점 목록은 원본을 수정하지 않는다.

### 1.2 후속으로 미룰 기능

| 후속 기능 | 1차에서의 처리와 영향 |
|---|---|
| ICP 내부 자동 배율 보정 | 실행하지 않는다. 크기가 다른 자료는 기존 마커 배율 또는 수동 배율로 먼저 맞춘다. |
| 삼각형 표면에 대한 최근접점 정밀화 | 메시 정점을 검색 대상으로 사용한다. 큰 삼각형·불균일한 정점 밀도에서 기존 표면 방식과 결과가 달라질 수 있다. |
| 점군 법선 추정과 점군의 점–평면 최적화 | 점군끼리는 점–점 방식으로 처리한다. 법선 추정 비용과 설정은 추가하지 않는다. |
| 독립 양방향 품질 평가와 여러 후보의 자동 비교 | 실행 중 기본 유효성 검사는 유지하되, 기존 겹침 평가 RMS와 후보 선택 기능은 후속으로 분리한다. |
| GPU 가속 및 작업 간 KD-tree 상주 재사용 | 1차는 CPU와 작업 단위 색인 재사용으로 한정한다. |

위 기능을 생략한 결과를 기존과 같은 품질 평가를 통과한 것으로 표시하지 않는다. 입력 조합 지원을 없애는 변경은 포함하지 않는다.

## 2. 교체 근거

### 2.1 Artec에서 확인한 실행

이미 정렬된 두 메시를 다시 Align한 한 번의 실행에서 다음을 확인했다. 원본 정점 전체를 입력으로 유지하는 것과 모든 점이 매 반복의 유효 대응쌍으로 사용되는 것은 다르다.

| 항목 | 관측 내용 |
|---|---|
| 입력 크기 | 작은 메시 188,400점, 큰 메시 10,173,478점, 합계 20,486,237삼각형 |
| 대응 검색 | 작은 쪽 188,400점에서 큰 쪽 KD-tree로 단방향 검색 |
| 검색 조건 | 리프 용량 16, 검색 반경 10, 법선각 제한 45도 |
| 거리 제거 | 첫 검색 성공 147,381쌍 중 먼 쪽 약 5%인 7,369쌍의 가중치를 0으로 처리 |
| 최적화 | 유효 140,012쌍을 이용한 Chen–Medioni 계열 점–평면 6변수 강체 계산 |
| 반복 | 상한 30회, 실제 변환 갱신 1회·대응 검색 2회, 상대 변화에 의한 종료 |
| 색인 | 전처리·입력 구성에서 총 4회 구축했지만 ICP 반복 사이에는 재구축하지 않음 |
| CPU | 전처리 일부는 두 스레드, 관측한 ICP 본체의 CPU 시간은 한 스레드에 집중 |
| 시간 | 전체 계측 구간 5.319초, ICP 구간 2.831초 |

검색 반경 10은 프로그램 좌표 단위이며 10mm로 확인된 값이 아니다. 초기 조사에서는 종료 기준 0.001만 확인했으나, 후속 [종료식 분석](COLMAP_Align_Artec_종료식_분석.md)에서 정확한 분모와 `오차 또는 (회전 그리고 이동)` 결합을 확인했다. 작은 쪽을 질의한 한 실행만으로 모든 입력에 대한 Artec의 자동 방향 정책을 확정하지 않는다. 또한 이 기록은 초기 배치가 나쁜 경우의 반복 횟수나 모든 실행 경로의 GPU 사용 여부를 증명하지 않는다.

근거: [Artec 실측 정리](../output/align_comparison_20261021/artec_reference.json).

### 2.2 현재 COLMAP Align에서 확인한 비용

동일한 두 메시로 실행한 현재 Align은 첫 실행 23.836초, 재실행 22.116초였다. 재실행의 주요 구간은 다음과 같다. 아래 구간은 서로 중복되지 않는다.

| 구간 | 재실행 시간 |
|---|---:|
| 입력 고정·검사·파일 준비 | 5.441초 |
| 계산기 내부 전처리 | 7.437초 |
| 강체 정렬 네이티브 호출 | 0.364초 |
| 배율 보정 네이티브 호출 | 4.968초 |
| 계산기 내부 기타 | 0.887초 |
| 결과 검증 | 2.660초 |
| 작업 파일 정리·경계 대기 등 | 0.359초 |

시작과 완료 시의 전체 배열 해시만 합계 5.156초이며, 이 비용은 위 입력 준비와 결과 검증에 이미 포함된다. 강체 단계는 34회 시도·33회 채택, 배율 단계는 266회 시도·265회 채택했다. 최종 후보는 시작 배치였고 품질 상태는 `REVIEW`였다. 반복 횟수를 줄이는 것만으로 전체 병목이 해결되지는 않는다.

Artec과 시간 비율은 약 4.2~4.5배지만, 검색 방향·배율·평가 범위·계측 경계가 다르므로 순수 ICP 엔진의 성능 배율로 사용하지 않는다.

## 3. 새 기본 정렬 계약

### 3.1 입력 조합과 검색 방향

다음은 새 엔진의 설계 결정이다. 검색 방향과 사용자 기준 A/P 역할을 별도로 관리한다.

| 이동 P / 기준 A | 질의점과 KD-tree 대상 | 오차 방식 |
|---|---|---|
| 메시 / 메시 | 유효 정점 수가 적은 쪽을 질의하고 큰 쪽에 색인을 구축 | 점–평면 |
| 점군 / 메시 | 점군을 질의하고 메시 정점에 색인을 구축 | 점–평면 |
| 메시 / 점군 | 기준 점군을 질의하고 이동 메시 정점에 색인을 구축한 뒤 결과를 역변환 | 점–평면 |
| 점군 / 점군 | 유효 점 수가 적은 쪽을 질의하고 큰 쪽에 색인을 구축 | 점–점 |

점 수가 같으면 P를 질의한다. 점군–메시는 점 수보다 메시 법선을 사용할 수 있는 방향을 우선하므로, 항상 작은 쪽을 질의하는 것은 아니다. A가 여러 레이어이면 기존 규칙대로 현재 좌표의 기준 그룹을 구성하고 각 점의 원본 레이어와 인덱스를 추적한다.

메시 법선은 유효 삼각형으로 계산한 면적 가중 정점 법선을 사용한다. 비균일 배율이 있으면 선형 변환의 역전치로 법선을 변환하고 정규화한다. 반사 변환·면 방향도 일관되게 처리한다. 점군–메시는 목표 메시 법선만으로 점–평면 계산이 가능하며, 질의 점군에 법선을 새로 만들지 않는다.

### 3.2 원본 보존과 입력 유효성

- 원본 유효점을 모두 계산 입력으로 유지한다. 고정 50,000점 표본, 메시 면적 표본, 메시 간소화를 새 기본 경로에서 수행하지 않는다.
- 메시의 퇴화면·잘못된 인덱스·비유한 좌표 검사는 기존 정책을 따른다. 제외 가능한 면과 정렬에 사용할 정점만 계산용 인덱스로 분리하며, 손상된 입력을 임의로 복구하지 않는다.
- 계산용 정점 수와 원본 정점·면 수를 별도 기록한다. 원본 출처·지문에 계산용 수치를 대신 넣지 않는다.
- 메시 법선이 없는 정점은 점–평면 대응에서 제외한다. 충분한 유효 대응을 얻지 못하면 명시적으로 실패시키며 다른 엔진으로 자동 재시도하지 않는다.

### 3.3 좌표와 변환 적용

현재 공통 정렬 행렬을 `C0`, 형상별 표시·축 변환을 `Nᵢ`라고 하면 계산 입력은 `C0 × Nᵢ × 원본 좌표`다. A도 자신의 현재 확정 변환을 적용한 좌표로 구성한다.

- P에서 A로 계산한 강체 보정이 `Δ`이면 새 P 공통 정렬은 `Δ × C0`다.
- A에서 현재 P로 계산한 보정이 `S`이면 새 P 공통 정렬은 `S⁻¹ × C0`다.
- A는 이동하지 않는다. 연결 카메라·점군·메시에는 같은 P 공통 정렬을 적용한다.
- 새 보정의 회전은 반사가 없는 회전이고 추가 배율은 1이다. 기존 `C0`와 표시 변환에 들어 있는 배율을 초기화하지 않는다.
- 기존 마커 초기 정렬과 일반 직접 Align이 같은 변환 계약을 사용한다.

## 4. 계산 흐름

### 4.1 준비와 KD-tree

1. 대상 레이어, 형상 종류, 원본 개정 번호, 축·표시·정렬 변환을 작업 입력으로 고정한다.
2. 검증된 원본 좌표와 필요한 법선을 네이티브 작업에 전달한다.
3. 검색 대상의 모든 유효점으로 KD-tree를 한 번 구축한다. 초기 리프 용량은 관측값과 같은 16으로 두고 측정한다.
4. ICP 동안 대상 좌표와 색인은 고정하고, 질의점과 질의 법선의 현재 변환만 갱신한다.
5. 완료·실패·취소 시 해당 작업의 색인과 임시 파일을 해제한다.

1차는 작업마다 하나의 네이티브 실행 세션을 사용한다. 반복마다 프로세스를 만들거나 색인을 다시 만들지 않는다. 작업 간 색인 상주 기능은 후속으로 둔다.

### 4.2 대응 검색과 제거

- 노드 경계 상자와 현재 최선 거리로 가지치기하는 정확 최근접 검색을 사용한다.
- 메시–메시는 거리와 법선 조건을 모두 만족하는 최근접점을 찾는다. 최근접점 하나를 찾은 뒤 법선이 맞지 않는다는 이유로 검색을 끝내면 안 된다.
- 법선 조건은 45도부터 검증한다. 면 방향이 반대인 자료도 처리하도록 새 엔진은 `abs(dot) ≥ cos(45°)`를 초기 정책으로 삼는다. 이는 Artec의 법선 부호 처리까지 확인했다는 뜻이 아니다.
- 질의 법선이 없는 점군–메시와 점군–점군에는 법선각 필터를 적용하지 않는다.
- 유효 대응의 유클리드 거리 중 먼 쪽 5%를 제거 마스크와 가중치 0으로 표시한다. 개수는 내림하고 동일 거리에서는 원본 식별자로 순서를 고정한다.
- 점·대응 배열을 매 반복 물리적으로 삭제하지 않는다. 검색 실패, 법선 제외, 거리 제거의 수치를 구분한다.

반경은 Artec의 10을 그대로 복사하지 않는다. 기존 `max(0.01D, 3h, 2e)` 규칙을 출발점으로 삼되, `D`는 작은 형상의 대각선, `h`는 검색 대상 점 간격, `e`는 사용할 수 있는 초기 마커 RMS로 정의한다. 점 간격은 KD-tree를 이용한 제한된 결정적 검사점으로 추정하며, 이 검사점 선택은 ICP 입력 축소와 구분한다. 마커가 없으면 `e` 항은 사용하지 않는다.

반경이 `0.05D`를 넘는 경우의 초기 배치·밀도 확인 정책도 유지한다. 반경과 점 간격 추정 규칙은 1단계에서 점군 사례까지 검증해 확정한다. 실행 도중 성공할 때까지 반경을 자동 확대하는 기능은 넣지 않는다.

### 4.3 강체 최적화

| 방식 | 계산 계약 |
|---|---|
| 점–평면 | 목표 정점의 접평면에 대한 잔차를 6변수 회전·이동 선형계에 누적하고 강체 보정 계산 |
| 점–점 | 대응점의 중심과 공분산을 누적하고 SVD 기반 강체 해 계산, 반사 제거 |

점–평면은 삼각형 내부의 실제 최근접 표면점을 구하는 연산과 다르다. 따라서 기존 BVH 표면 정렬과 수치적으로 같은 결과를 보장하지 않는다.

계산은 중심·대표 길이로 정규화하고 핵심 누적과 작은 행렬 계산에는 배정밀도를 사용한다. 점–평면은 6개 이상 대응과 유효 계수 6을, 점–점은 적어도 3개의 비공선 대응과 공간 분포를 검사한다. 단일 평면 등 구속이 부족한 입력에 임의 해를 적용하지 않는다. 행렬 분해 구현·허용오차는 기존 검증된 수학 코드의 재사용 가능성을 확인한 뒤 고정하고, 필요 라이브러리는 버전·라이선스·배포 항목에 기록한다.

### 4.4 반복과 종료

초기 정책은 최대 변환 갱신 30회다. 각 갱신 뒤 대응을 재검색하고 종료를 판정하므로 검색 횟수와 갱신 횟수를 별도 기록한다. 이미 정렬된 입력도 실제 검사 없이 성공으로 간주하지 않는다.

초기 설계에서는 Artec의 미확인 종료식을 추정하지 않고 다음 세 조건의 동시 만족을 검증 후보로 정했다. 이후 확인한 Artec의 실제 조건 결합은 [후속 분석](COLMAP_Align_Artec_종료식_분석.md)과 다르며, 아래는 우리 엔진의 설계다.

- 정규화된 목적함수 RMS의 상대 변화: `abs(E이전 − E현재) / max(E이전, ε) ≤ 0.001`
- 추가 이동량: `norm(δt) / D ≤ 0.001`
- 추가 회전각: `angle(δR) ≤ 0.001 rad`

여기서 `ε`는 정규화 좌표계의 영 나눗셈 방지 하한이다. 세 값은 **Artec 동일값을 보증하는 출시 기준이 아니라 검증 시작값**이다. 허용 정렬 오차를 만족하지 못하면 더 엄격하게 조정하고 고정한다. 대응 수 급감은 수렴으로 인정하지 않는다.

2026-10-21 최초 검증에서는 상대 목적함수 RMS `1e-6`, 정규화 이동 `1e-8`, 회전 `1e-8 rad`를 사용해 실제 두 메시에서 30회 상한 및 `REVIEW`를 기록했다. 이후 사용자 요청으로 세 허용치를 모두 `0.001`로 완화했다. 대응 수 동일 조건, 한 갱신의 절반 이상 급감 검사, 기존의 세 조건 동시 만족 구조는 유지한다. 이는 별도로 확인한 [Artec 종료식](COLMAP_Align_Artec_종료식_분석.md)을 그대로 구현한 변경이 아니다.

갱신 전후에는 같은 대응쌍·같은 가중치로 목적함수를 비교해 수치적 악화를 검사한다. 비유한 값·구속 부족·입력 변경이면 결과 적용을 차단한다. 악화된 갱신은 채택하지 않고 직전 유효 결과에 검토 사유를 남긴다. 상한 도달도 수렴 성공과 구분해 `REVIEW`로 표시한다. 실패나 검토 상태를 해결하기 위해 기존 엔진으로 자동 전환하지 않는다.

### 4.5 CPU 병렬화

C++ 작업기에서 독립적인 질의점 검색, 대응 통계와 행렬 기여 누적을 병렬화한다. 기존 oneTBB 기반 CPU 제한을 재사용하고 Blender 조작은 메인 스레드에 남긴다. 행렬 기여는 고정된 블록 순서로 합쳐 스레드 수에 따른 차이를 관리한다.

Artec에서 본체가 한 스레드였다는 이유로 같은 제한을 재현하지 않는다. 검색 구조와 작업량을 참고하면서 기존 CPU 자원을 활용한다. 실제 병렬화 효과와 메모리 대역폭 한계는 1스레드와 제품 기본 스레드 수로 각각 측정한다.

## 5. 전처리와 입력 변경 검증

엔진 교체와 함께 원본 검증·해시의 반복 비용을 줄인다. 검사 호출을 삭제하는 방식으로 최적화하지 않는다.

1. Align이 독점 소유하는 원본 버퍼와 수정 경로를 조사한다. 불러오기, 연결 OBJ 변경, 복원, Undo/Redo, 레이어 삭제·재생성에서 개정 번호와 캐시 무효화를 확인한다.
2. 원본 검증 결과·지문·법선을 모델 식별자, 버퍼 개정 번호, 계산 정책 버전에 묶어 재사용한다. 파일명이나 점 수가 같다는 이유로 공유하지 않는다.
3. 실행 입력은 변경 불가능한 소유 버퍼와 작업 토큰으로 고정한다. 단순히 배열의 쓰기 플래그를 끄는 것만으로 외부 참조의 변경을 차단했다고 간주하지 않는다.
4. 작업 중에는 모델·버퍼 개정 번호와 변환 토큰을 검사한다. 완료 시 같은 입력임이 확인된 결과만 미리보기로 넘긴다.
5. 원본의 모든 변경 경로가 추적된다는 검증을 통과한 경우에만 시작·완료 시 전체 배열 재해시를 제거한다. 이 조건을 충족하지 못하면 기존 검사를 유지하고 성능 목표 미달 원인으로 기록한다.

캐시는 Align 모델 수명 안에서 소유하고 메모리 예산·해제 규칙을 둔다. 원본 형상 캐시와 현재 변환에 종속되는 법선·작업 좌표를 구분한다. 중복 불러오기, 파일 복원, 작업공간 종료 때 잘못된 재사용이나 누수가 없어야 한다. 가져오기 단계로 옮긴 비용은 별도 측정하여 Align 시간 감소만으로 전체 작업 시간이 줄었다고 보고하지 않는다.

2026-10-21 조사에서는 원본의 쓰기 가능한 별칭을 완전히 배제할 수 없어 시작·완료 전체 SHA-256을 유지했다. 최대 512MiB·8항목 캐시와 동일 지문을 계산하는 Windows CNG를 새 경로에만 적용했다. 지문 형식·모든 검사 바이트·구엔진의 계산 방법은 유지하며 가져오기 단계로 비용을 옮기지 않았다.

## 6. 통합과 호환성

새 엔진 식별자는 가칭 `POINT_KD_ICP`, 알고리즘 버전은 가칭 `point-kd-icp-v1`로 분리한다. 기존 CCCoreLib 결과·품질 기록을 새 엔진에서 생성한 것처럼 해석하지 않는다.

기존 Align 버튼과 미리보기 흐름은 유지하고 내부 호출만 교체한다. 새 기본 경로에서 배율 보정이 호출되지 않도록 오퍼레이터의 실제 인자까지 바꾼다. 현재 화면 속성 하나를 끄는 것으로 대체하지 않는다. 엔진 선택 UI는 1차에 추가하지 않는다.

새 상태창에는 `정렬 대응 RMS`, 유효 대응 수, 변환 갱신 횟수와 종료 사유를 표시한다. 이 RMS는 최적화 대응에 종속되므로 기존 독립 `겹침 평가 RMS`와 구분한다. 평가 미실시 여부를 결과 스키마에 기록하고 기존 PASS 기준을 그대로 재사용하지 않는다. 현재 미리보기 승인 정책과 실패·취소 시 이전 확정 결과 보존은 유지한다.

구버전 `.blend`의 확정 행렬과 원본 출처는 계속 읽고 내보낼 수 있어야 한다. 과거 품질 기록은 기존 방식으로 표시하거나 구버전 기록임을 명시한다. 새 Align 실행 시에만 새 결과를 생성한다. 호환성 검증이 끝나기 전에는 기본 배포 엔진을 전환하지 않는다.

## 8. 검증 계획

### 8.1 알고리즘과 원본 보존

- KD-tree 결과를 작은 자료의 전수 검색과 비교한다. 가장 가까운 점의 법선이 맞지 않지만 다음 점은 맞는 경우, 반경 경계, 중복점, 동률, 비유한 좌표를 포함한다.
- 비대칭 형상의 알려진 회전·이동으로 네 입력 조합과 A/P 반전 결과를 확인한다. 잡음 없는 충분한 겹침 자료의 초기 목표는 이동 오차 `≤ 10⁻⁶D`, 회전 오차 `≤ 10⁻⁴ rad`이며 이를 만족하도록 종료 허용오차를 검증한다.
- 희소 점군, 밀도가 다른 점군, 일부 겹침, 이상점, 법선 반전, 큰 삼각형, 단일 평면·직선의 구속 부족을 검사한다. 수렴 가능한 사례와 명시적으로 거절할 사례를 나눈다.
- 마커 초기 배율, 비균일 표시 배율, 개별 축 변환, 여러 A 레이어, 동일 원본 중복 레이어, 연결 카메라·OBJ의 공통 이동을 확인한다.
- 승인·버리기·Undo/Redo·저장·복원 뒤 원본 점 ID, 정점·면 순서, UV·재질과 내보내기 계약을 검사한다.

### 8.2 실행과 실패 처리

- 준비·색인 구축·검색·최적화·결과 수신 각각에서 취소하고 이전 확정 상태와 임시 파일 정리를 확인한다.
- 작업 중 형상·축·마커·정렬 입력 변경, 같은 점 수의 내용 변경, 레이어 삭제, 파일 로드, 확장 해제, 작업기 비정상 종료를 검사한다.
- 1스레드와 기본 CPU 설정의 결과를 수치 허용오차 안에서 비교하고 자원 제한·취소 반응·메모리 반환을 확인한다.
- 소스 검사, 네이티브 테스트, Blender 통합 검사, ZIP 빌드, 실제 설치본 검사를 각각 기록한다. 소스만 통과한 상태를 설치본 검증 완료로 보고하지 않는다.

### 8.3 실제 자료의 속도·정확도

기준 자료는 작은 메시 188,400정점·357,749삼각형과 큰 메시 10,173,478정점·20,128,488삼각형이다. 사용자의 현재 장면을 덮어쓰지 않는 검증 복제본에서 시작 변환을 고정한다.

1. 이미 정렬된 상태와 알려진 회전·이동을 추가한 상태를 따로 측정한다. A/P를 뒤집은 경우도 포함한다.
2. 첫 실행과 재사용 실행을 구분한다. 비교 설정마다 준비 실행 1회 뒤 측정 5회를 교차 수행하여 중앙값과 범위를 기록한다.
3. 기존 엔진과 새 엔진에 같은 입력·시작 위치·스레드 제한을 사용한다. 버튼 호출부터 결과 미리보기 준비 완료까지를 사용자 대기 시간으로 측정한다.
4. 준비·법선·색인·검색·제거·행렬 계산·결과 검증·프로세스 통신을 분리하고 CPU 시간과 최대 메모리도 기록한다. 캐시 생성 비용은 빠뜨리지 않는다.
5. 새 기본 실행에서 제외한 독립 평가 도구를 **시험 전용으로** 사용해 같은 고정 평가점의 거리 분포를 비교한다. 기준선 대비 RMS·상위 95% 거리와 알려진 변환 오차를 함께 본다. 기존 `REVIEW` 결과를 정답으로 간주하지 않는다.
6. 점군–메시와 점군–점군은 별도 자료로 검증한다. 메시 두 개의 속도만으로 전체 입력 조합의 성능을 대표하지 않는다.

성능의 초기 목표는 위 두 메시의 이미 정렬된 사례에서 **전체 대기 시간 중앙값 8초 이내**다. 이는 기존 약 22초에 대한 개발 목표이며 Artec의 5.319초 재현을 보장하는 값이 아니다. 같은 고정 평가의 RMS와 상위 95% 거리가 기준선보다 5% 넘게 악화되면 별도 원인 분석과 재설계 없이 통과시키지 않는다. 기준선 오차가 0에 가까우면 수치 허용오차와 알려진 변환 오차로 판정한다. 속도를 달성해도 원본 보존·정확도·실패 처리 중 하나가 미달하면 기본 엔진으로 전환하지 않는다.

## 9. 완료 조건

- [x] 점군–점군, 점군–메시 양방향, 메시–메시가 새 경로로 동작한다.
- [x] 기본 Align에 면적 표본 생성, BVH 표면 검색, 추가 배율 보정, 독립 후보 비교가 호출되지 않는다.
- [x] 기존 배율·기준 A·원본 형상·연결 카메라와 표시 변환이 보존된다.
- [x] 입력 변경과 취소를 안전하게 처리하고 미리보기·승인·저장·복원이 호환된다.
- [x] 실제 데이터의 시간·정확도·메모리 결과와 제한 사항이 기록되어 있다.
- [x] 검증용 ZIP과 격리 설치본이 검증한 소스·네이티브 산출물과 일치한다.
- [x] 완료 문서에 새 기본 경로와 미구현 후속 기능이 정확히 반영되어 있다.

완료 항목은 1차 구현과 검증 자료의 완성을 뜻하며 모든 입력에 대한 정밀도 목표 달성을 뜻하지 않는다. 실제 두 메시의 정렬 상태 중앙값은 기존 `22.991초`에서 새 엔진 `5.828초`로 줄었고, 세 시작 조건 모두 고정 표면 RMS·95백분위 기준을 통과했다. 반면 조밀한 점군–성긴 메시의 모서리 접평면 근사는 알려진 정답 RMS/D `2.134e-4`로 목표 `1e-6`에 미달했다. 8.3절의 정확도 조건에 따라 현재 브랜치의 새 프로필은 검증용으로 제공하고, 사용자 설치본·루트 ZIP·운영용 기본 배포는 전환하지 않았다. 표면 정밀화는 후속 범위로 유지한다.

- [전처리 반복 계산 최적화 계획](COLMAP_Align_전처리_반복계산_최적화_계획서.md): 기존 성능 문제와 검증 근거로 사용한다.

기존 계획서의 50,000점 표본, 강체 200회·배율 1,000회 상한, 추가 배율과 독립 후보 평가 유지 조건은 당시 CCCoreLib 경로의 개선 범위였다. 이번 사용자 요청에 따른 **새 기본 엔진에서는 이 문서의 변경 범위를 적용**한다. 기존 문서의 과거 구현 사실을 수정하거나 다른 도구의 규칙까지 대체하지 않는다.
