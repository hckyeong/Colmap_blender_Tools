# 스텐실 Ctrl 임시 지우개

- 요청: 스텐실 텍스처가 연결된 페인팅 상태에서 Ctrl을 누르는 동안 Erase Soft를 사용하고, 놓으면 이전 브러시와 도구로 복귀한다.
- 범위: Projection Paint 전용 3D 뷰, 일반 페인트 레이어, 카메라 뷰의 실제 연결된 Draw 브러시. 연결 해제·Mask·Clone·일반 Blender 작업공간에는 적용하지 않는다.
- 원래 브러시 자산과 도구를 입력 세션에만 보관한다. Blender 기본 Essentials의 Erase Soft 자산을 활성화하며 원래 스텐실 브러시의 텍스처·배치·색·강도는 수정하지 않는다.
- Ctrl+클릭의 기본 반전 대신 기본 `paint.image_paint`를 `NORMAL`로 호출한다. 실제 스트로크는 Blender가 처리한다. 스트로크 도중에도 Ctrl 해제를 받도록 관찰자를 스트로크 처리기 앞에 연결한다.
- Ctrl 해제, 창 비활성화, 작업공간·모드 변경, 종료, 저장·불러오기·실행 취소, 확장 해제 시 원래 자산을 복구한다. 양쪽 Ctrl을 함께 누르면 마지막 Ctrl을 놓았을 때 복구한다. 다른 Ctrl 단축키는 원래 브러시로 복귀한 뒤 기본 처리기로 전달한다.
- 임시 지우개 동안 도구·스텐실 자동 추적은 기존 연결을 유지하며 원래 브러시를 덮어쓰지 않는다. 장기 복구 필드나 영구 RNA 상태를 추가하지 않는다.
- 검증: 실제 Blender 입력 이벤트로 전환·복귀, 알파 감소, 양쪽 Ctrl, 스트로크 중 해제, 범위 밖 입력, 종료 복구 및 등록·해제 대칭을 확인한다. 최신 설치 ZIP을 저장소 최상위에 갱신한다.

근거: [Blender Texture Paint 브러시](https://docs.blender.org/manual/en/5.2/sculpt_paint/texture_paint/brushes.html), [Blender 브러시 자산 API](https://docs.blender.org/api/5.2/bpy.ops.brush.html). 실제 Blender 5.2에서 Erase Soft는 `DRAW`·`ERASE_ALPHA`이고 텍스처가 없는 기본 자산으로 확인했다.

## 구현·검증 · 2026-10-06

- 0.3.74에 구현했다. `stencil_erase.py`가 Ctrl 입력 수명과 기본 브러시 자산 전환을 담당하며 기존 자동 추적기는 임시 지우개를 사용자가 바꾼 도구로 기록하지 않는다.
- 독립적인 Blender 5.2 화면 프로세스에 실제 UV 평면·이미지·카메라·스텐실을 만들고 창 이벤트 큐로 키·마우스를 입력했다. 사용자 프로젝트를 변경하거나 저장하지 않았다.
- 실제 Ctrl 스트로크 후 최소 알파가 1.0에서 0.007843으로 감소했다. 원래 브러시 포인터·색·강도·크기·스텐실 배치와 연결은 복귀 후 동일했다.
- 실제 화면 검사 15개를 통과했다: 전환·지우기·복귀, 양쪽 Ctrl, 스트로크 도중 해제, 연결 해제·Mask·Clone 제외, 작업공간·모드 변경, 종료·저장·실행 취소 장벽·창 비활성화·확장 해제 복구.
- 등록·해제 회귀 15개와 기존 도구 연결 검사 8개를 통과했다. 최상위 ZIP 빌드의 구조·공존·도구 핵심 검사 314개, 통합 등록·해제, CCCoreLib 실제 정렬 검사도 통과했다.
- 검증 결과: `build/verification/stencil-erase-20261006/gui.json`, `build.log`. 새 기능이 들어간 전체 설치본은 Blender 재시작 후 활성화한다.
