# 선택적 Sim(3) 정밀 정렬

2026-10-22 · `codex/artec-align-engine`

## 변경 계획

- Align에 `배율 함께 보정 (Sim(3))` 선택 항목을 추가한다. 기본값은 꺼짐이며 기존 강체 계산과 종료식을 유지한다. 3점 마커 배율 옵션과 독립적이다.
- 점대점은 대응점 중심·공분산과 원본 분산으로 양수 균일 배율을 함께 구한다. [Eigen의 Umeyama 설명](https://www.eigen.tuxfamily.org/dox/group__Geometry__Module.html)을 수학적 기준으로 사용한다.
- 점평면은 정규화 좌표 `q`, 대상 법선 `n`에 대해 기존 행 `[q×n, n]`에 로그 배율 미분 `q·n`을 추가한 7자유도 선형계를 푼다. 배율은 `exp(증분)`으로 양수를 유지한다. 법선에는 배율을 제외한 회전만 적용한다.
- 기준 KD-tree·대응 제거·전체점 입력은 유지한다. 원본 정점·면·UV는 수정하지 않고 P의 Sim(3) 변환만 미리보기·승인한다. 역방향 질의 결과도 원래 P 방향으로 역변환한다.
- 배율 보정 시 기존 상대 변화 종료식과 함께 `abs(log(추가 배율)) < 1e-6`을 요구한다. 이는 Artec에서 확인한 배율 종료식이 아니라 이 기능의 별도 종료 조건이다. 강체 모드의 종료식은 변경하지 않는다.
- 계수 부족·비유한 값·반사·전단은 실패 처리하고 목적함수 증가·대응 급감·반복 상한의 기존 검토 조건을 유지한다. 자동 강체 전환이나 동일 모델 판별 특례는 추가하지 않는다.
- Python 작업 계약·결과 검증·진행 표시·출처 저장에서 선택한 모드와 실제 배율을 검증한다. 취소·결과 버리기·승인·실행 취소의 기존 경계를 보존한다.

## 검증 계획

- 알려진 배율·회전·이동의 점대점/점평면 정답, 역방향·혼합 입력·큰 좌표·스레드 재현성·퇴화 입력·결과 변조를 검증한다.
- 현재 두 모델에서 동일 초기 행렬로 강체/Sim(3)를 교차 실행한다. 전체 정점의 동일 번호 거리로 독립 정확도를 측정하고 반복 수·전체 시간·배율·검토 상태를 기록한다.
- 각 모델의 원본 정점·면·UV 내용을 전후 비교하며 사용자 선택·시점·확정 변환을 보존한다. 실제 계산 결과는 사용자가 승인할 수 있는 미리보기로 제공한다.
- 소스·정식 빌드·격리 설치 검증 후 설치본을 갱신한다. 사용자 화면을 전환하지 않고 데스크톱2의 기존 Blender를 사용한다.

## 실행 결과

0.3.83에 구현하고 사용자 설치본과 실행 중인 데스크톱2 Blender에 반영했다. 현재 장면에는 **배율 함께 보정 (Sim(3))**을 켜고 최종 결과 미리보기를 남겼다. 사용자가 정렬 승인으로 확정할 수 있으며 기존 확정 변환·마커·선택·시점·이력은 보존했다. 원본 `.blend` 파일은 저장하지 않았다.

### 실제 두 모델 비교

각 모델 30,109,486정점·60,206,247삼각형이다. 원본 정점과 면이 전체 내용까지 같은 두 모델임을 읽기 전용으로 확인했다. 이 일치는 독립 정확도 평가에만 사용했으며 제품 정렬에는 동일 파일·동일 모델 특례를 추가하지 않았다.

공개 Align 시작 경계에서 결과 미리보기 준비까지 측정했다. 같은 초기 행렬에서 모드별 준비 실행 1회 후 순서를 교차해 3회씩 측정했다. 원본 전체 해시 검사·설치·정확도 평가 시간은 정렬 시간에서 제외했다. 화면 프레임 표시 완료 시각은 별도로 측정하지 않았다. 측정 중 다른 빌드·성능 검증을 병행하지 않았다.

| 항목 | 배율 고정 | Sim(3) 배율 보정 |
|---|---:|---:|
| 전체 시간 중앙값 | 29.095초 | 60.617초 |
| 전체 시간 범위 | 28.596~29.446초 | 59.515~60.619초 |
| 입력 전달·작업 시작 중앙값 | 11.220ms | 13.218ms |
| 반복 수 | 1회 | 5회 |
| A 대비 P 배율 | 1.008559920171 | 1.000000000000 |
| 전체 동일 정점 RMS | 22.588222mm | 7.845580e-13mm |

mm는 현재 장면의 Metric·단위 배율 1.0을 기준으로 환산한 값이며 실제 유물의 물리 치수를 별도로 측정한 것은 아니다. Sim(3) 결과의 약 1e-12mm 오차는 배정도 부동소수점 계산 정밀도 수준이다. 최근접 대응 RMS가 아닌 **30,109,486개 전체 동일 번호 정점의 세계좌표 거리**로 평가했다. 두 모드 모두 반복 실행 간 최종 행렬이 완전히 같았다.

0.3.82 실제 설치본의 비교 실행은 30.642초였다. 새 버전의 배율 고정 결과 행렬은 이전 설치본과 최대 차이 **0**이었다. 두 버전 모두 이번 재실행에서 대응 RMS가 0.009531584022911023→0.009531597188347384로 미세하게 증가하여 `RMS_WORSENED / REVIEW`가 됐다. 이 검토 조건은 변경하거나 숨기지 않았다. Sim(3)는 준비 실행과 측정 실행 모두 `PASS`, 검토 사유 없음이었다.

### 시간 차이의 원인

초기 +0.855992% 배율 오차를 보정하므로 Sim(3)는 5회 갱신했다. 배율 고정은 해당 오차를 해결하지 못한 상태에서 1회 만에 종료했다. Sim(3)의 네이티브 구간 중앙값은 대응 제외를 위한 정렬 44.129초, 최근접 검색 5.609초, KD-tree 생성 3.855초, 선형계 풀이 합계 0.378초였다. 추가 시간의 대부분은 반복 증가에 따른 대응 검색·제외 처리다. 배율까지 맞춘 상태에서 다시 Align하는 시간은 이번 표에 포함하지 않는다.

### 원본·설치·회귀 검증

- 각 모델의 정점·삼각형·원본 면/루프 번호·UV 좌표·UV 성분/인덱스·재질 인덱스 전체 배열을 각각 SHA-256으로 전후 대조했다. 원본 불변성과 GPU 객체 재사용을 확인했다. 원본 OBJ·열린 `.blend` 파일의 크기와 수정 시각도 유지됐다.
- 네이티브 29개, 작업 계약 11개, Blender 정렬 수명 9개 검사를 통과했다. 알려진 배율·회전·이동, 점대점·점평면, 혼합 입력·역질의, 스레드 재현성, 배율/반사/전단 변조, 취소·미리보기·버리기·승인·실행 취소·출처 저장을 포함한다.
- 정식 빌드 314개 검사와 등록·스테이징·ZIP 검증을 통과했다. 격리 설치에서 네 입력 조합·양방향의 강체 8건과 Sim(3) 8건 및 기존 밀도 차이 경계 2건을 검증했다.
- Align 소스 회귀는 52개 파일을 통과했다. `test_display_axes.py`의 불완전한 모형 입력에는 `points.positions`가 없어 실패했다. 같은 테스트를 보존한 0.3.82 설치 ZIP의 소스에서도 실행하여 동일 실패를 확인했다. 이번 변경 범위 밖의 기존 오류로 남겼다.
- 큰 좌표 원점의 합성 Sim(3) 시험에서는 좌표 오차가 2e-7 미만으로 복원되지만 반올림 수준의 목적함수 증가로 `REVIEW`가 발생했다. 이를 성공으로 바꾸는 우회나 검토 조건 완화는 추가하지 않았다. 일반적인 부분 겹침·국소 변형에 대한 절대 정확도 보증은 아니다.
- 설치본 1,235개 파일이 검증 ZIP과 바이트까지 일치한다. 사용자 환경설정 파일을 보존했으며 확인된 제품 변경 파일은 17개다. 사용자 화면 전환·창 활성화 없이 데스크톱2의 기존 Blender를 사용했다.
