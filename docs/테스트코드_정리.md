# 테스트 코드 정리

작성일: 2026-10-22. 대상 브랜치: `main`.

## 요청과 범위

- 사용자가 저장소의 테스트용 코드를 모두 정리하고 다시 푸시하도록 요청했다.
- `tests/`의 회귀·실험·벤치마크·보조 자료와 별도 실행 스크립트를 제거한다.
- 제품 빌드가 삭제된 파일을 호출하거나 네이티브 재빌드 묶음에 포함하지 않도록 배포 도구와 CMake를 함께 정리한다.
- 애드온 동작·정렬 알고리즘·사용자 데이터는 변경하지 않는다. 제품 실행 환경 검사, 의존성 잠금·원문·바이너리·라이선스 무결성 검사는 유지한다.
- 과거 테스트 코드와 실행 결과는 커밋 `61a764f300dccfdef09311ddf4a553673dfa2716`의 Git 이력으로 안내한다. 과거 문서의 검증 기록을 새 검증 결과로 바꾸지 않는다.

## 확인 방법

삭제된 경로를 참조하는 실행 코드가 없는지 확인하고, 두 네이티브 런타임과 설치 ZIP을 정식 빌드한다. Python·PowerShell 구문, 확장 매니페스트, 런타임 실행 환경과 ZIP 무결성을 검사한다. 창 없는 Blender에서 격리 설치와 등록·해제를 확인한다. 독립 회귀 테스트는 제거되므로 이번 확인을 회귀 테스트 통과로 표시하지 않는다.

## 완료 결과

- Git 추적 파일 310개를 제거했다. `tests/` 307개와 빌드 도구의 테스트·벤치마크 실행기 3개다.
- 제품 Python 337개 파일과 남은 PowerShell 빌드 도구의 구문 검사를 통과했다. 제품 실행 코드에 삭제된 테스트 경로를 참조하는 호출이 없다.
- CCCoreLib·PointKD 네이티브 런타임을 다시 빌드하고 기본 PointKD 프로필의 `colmap_tools.zip`을 갱신했다. 기능 변경이 없어 버전은 `0.3.83`을 유지했다.
- 빌드 과정의 실제 정렬·실행 환경 검사, 매니페스트·파일 해시·라이선스 검사, 설치 ZIP과 두 재빌드 원문 ZIP의 무결성 검사를 통과했다. 프로젝트 테스트 코드와 `native_test_report.json`은 배포 묶음에 포함하지 않는다. 고정된 외부 의존성 원문은 유지한다.
- Blender 5.2.0 LTS의 창 없는 프로세스에서 최종 격리 설치·등록·해제를 확인했다. GUI 창은 열지 않았다.
- 설치 ZIP: 49,002,778바이트, 1,234개 항목. SHA-256: `569c2236e8cc65703f62330b1106d7e0d354752737dc4f4859b268db2ef86217`.

## 로컬 확인 과정의 처리

첫 설치 확인에서는 임시 설정 폴더가 없어서 Blender가 기존 설정 경로를 사용했고, 확장 저장소 목록이 변경됐다. 당일 백업에서 저장소 목록만 복원하여 다른 환경설정과 애드온 목록을 유지했고 기존 설치본을 다시 읽어 확인했다. 최종 확인은 모든 임시 폴더를 먼저 생성하고 실제 설정 경로를 단언한 뒤 수행했으며, 사용자 환경설정 파일의 전후 해시가 동일했다.

Git에서 제외된 로컬 테스트 캐시의 재귀 삭제는 자동 승인 검토가 차단하여 남겼다. 해당 캐시와 기존 로컬 출력·캡처는 커밋에 포함하지 않는다.
