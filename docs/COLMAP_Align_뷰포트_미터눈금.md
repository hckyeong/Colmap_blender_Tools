# Align 뷰포트 1~10m 눈금

## 요청과 범위

Modifier의 미터 안내처럼 Align의 A·P 두 뷰에도 월드 원점 기준 +X·+Y 방향으로 `1 m`~`10 m`를 표시한다. 기준선과 1m 간격 짧은 눈금을 함께 그린다. 데이터 이동·회전·배율과 피벗 변경은 가이드 위치에 적용하지 않는다.

## 구현

- Align은 기존 GPU 표시 경로를 사용하므로 자체 `viewport/meter_grid_guide.py`에서 작은 선 배치와 화면 글자를 그린다. Modifier 모듈을 가져오거나 Scene 오브젝트·컬렉션을 추가하지 않는다.
- 기존 A·P 역할 판정과 두 그리기 핸들러 안에서만 호출한다. 정렬 입력·피킹·선택·프레이밍·내보내기 대상에 들어가지 않는다.
- Scene 단위가 없음이면 1 Blender 단위를 1m로 본다. Metric·Imperial에서는 `1 / scale_length`로 환산하며 전역 설정을 쓰지 않는다. 단위 설정은 그릴 때 읽어 변경을 즉시 반영한다.
- 줌·회전 시 글자의 위치는 실제 월드 눈금에 붙이고 글자 크기와 방향은 읽기 쉽게 화면 기준으로 유지한다. 시야 밖·뒤쪽·화면 가장자리의 안내 영역·겹치는 글자는 생략한다. 오버레이를 끄면 가이드도 숨긴다.
- 재사용하는 선 배치 정점 44개와 최대 글자 20개만 처리한다. 메시를 조회하거나 전체 형상 배열을 복사하지 않는다. 기존 핸들러 해제 경로에서 GPU 자원 참조를 정리한다.

## 검증

기존 뷰포트 회귀와 실제 GUI에서 A·P 양쪽 표시, 줌·회전·직교 시점, 단위 환산, 오버레이 숨김, 작업공간 이탈·재진입 및 자원 정리를 확인한다. 지정한 `C:/Users/gksru/Desktop/Untitled.blend`는 별도 검증 프로세스로 열고 원본 파일에 저장하지 않는다. 검증 산출물은 `build/verification/align-meter-guide/`에 보존한다.
