# 수렴 허용치 0.001 재검증

2026-10-21 · `codex/artec-align-engine` · Artec에서 사용했던 두 메시

**세 수치 허용치를 0.001로 바꾸자 같은 두 메시에서 3~6회에 수렴했으며 REVIEW가 사라졌다. 정렬 시간 중앙값은 26.5~29.1% 감소했다. 독립 표면 오차의 전체 RMS 증가는 0.0006% 미만이었다.**

## 변경 범위

상대 목적함수 RMS 허용치를 `1e-6 → 0.001`, 중심 이동량/대각선 허용치를 `1e-8 → 0.001`, 회전각 허용치를 `1e-8 → 0.001 rad`로 변경했다. Python 매개변수와 C++에서 생략한 매개변수의 기본값을 일치시켰다.

세 조건 동시 만족, 갱신 전후 대응 수 동일 조건, 급감·목적함수 악화 검사, 30회 상한, 원본 해시 검사, 입력 전체점 유지 및 스레드 수는 변경하지 않았다. 검토 표시를 강제로 끄는 코드는 추가하지 않았다.

후속 REA 분석에서 확인한 **Artec의 실제 종료식은 오차 또는 (회전 그리고 이동)**이며 정규화 분모도 다르다. 이번 변경은 기존 우리 엔진의 허용치 완화다. [Artec 종료식과 근거](COLMAP_Align_Artec_종료식_분석.md)를 참고한다.

## 측정 조건

- Blender 5.2.0 LTS 별도 백그라운드 프로세스에서 사용자 `test.align.blend`를 복원했다. 원본 장면을 저장하거나 결과를 승인하지 않았다.
- 작은 메시 188,400점·357,749면, 큰 메시 10,173,478점·20,128,488면. 합계 **20,486,237면**.
- 작은 메시 전체를 질의하고 큰 메시 전체로 KD 트리를 구성한다. 31스레드, 배율 고정, 같은 거리·법선·5% 제외 정책이다.
- 같은 새 실행 파일과 패키지를 사용해 이전 엄격 설정을 명시한 경로와 새 기본값의 실제 공개 정렬 경로를 비교했다. 기록된 매개변수 차이는 세 허용치뿐이다.
- 조건마다 각 설정을 한 번 준비 실행한 뒤, 실행 순서를 교차하며 각 5회 측정했다. 준비 실행 6회와 측정 30회, 합계 36회다.
- 시간은 작업 시작부터 미리보기 결과 수신까지다. 입력 준비·해시·외부 작업기·결과 검사를 포함하며 프로젝트 복원·화면 그리기는 제외한다.
- 최초 준비 실행은 캐시 상태가 다르므로 아래 비교에서 제외했다. 측정 중 빌드나 다른 성능 실험을 병행하지 않았다.

## 속도와 REVIEW

| 시작 조건 | 엄격 설정 중앙값 | 0.001 중앙값 | 시간 감소 | 갱신 횟수 | 0.001 결과 |
|---|---:|---:|---:|---|---|
| 이미 정렬된 상태 | 5.716초 | **4.128초** | 27.8% | 30 → **3** | 수렴·검토 사유 없음 |
| Z축 0.5°·이동 (0.6, −0.4, 0.2) 추가 | 5.832초 | **4.286초** | 26.5% | 30 → **6** | 수렴·검토 사유 없음 |
| 두 모델의 P/A 역할 반전 | 5.896초 | **4.180초** | 29.1% | 30 → **3** | 수렴·검토 사유 없음 |

기존 설정은 모두 `REVIEW / MAX_ITERATIONS`, 0.001은 모두 네이티브 `SUCCESS / CONVERGED` 및 상위 결과 품질 `PASS`였다. 반복마다 최종 행렬이 정확히 같았다. 명시한 엄격 설정의 행렬은 지난 검증 결과와도 정확히 일치했다.

측정 범위는 정렬 상태에서 엄격 5.663~5.880초, 완화 4.025~4.312초였다. 틀어진 상태에서는 5.699~5.999초와 4.187~4.382초, 역할 반전에서는 5.704~6.007초와 4.018~4.407초였다.

정렬 상태의 세부 중앙값은 KD 구축이 1.996→2.002초로 거의 같았다. 대응 검색은 0.994→0.127초, 먼 대응 제외는 0.560→0.072초로 줄었다. 반복 횟수 감소가 주요 원인이지만 입력 처리와 KD 구축 비용이 남아 전체 시간이 10배 빨라지는 것은 아니다.

세 번째 갱신의 목적함수 RMS 상대 변화는 약 0.00020693, 정규화 이동은 0.0000039473, 회전은 0.0000150689 rad였다. 전후 대응 수는 모두 174,006개였다. 기존 종료 논리에 의해 수렴한 결과다.

이전에 기록한 Artec 전체 시간 5.319초는 이미 정렬된 상태의 단일 계측이다. 이번 여러 회 측정과 계측 경계·부하가 같지 않으므로 성능 우열을 확정하는 기준으로 사용하지 않는다.

## 독립 정확도

원본 메시에서 방향별 30,000개 표면 표본을 고정하고, 초기 상태에서 선택한 겹침 평가점 **59,187개**를 모든 후보에 그대로 사용했다. 지난 검증과 표본·마스크 해시가 같다. 정확 삼각형 표면 거리로 평가했으며 새 후보마다 불리한 점을 추가 제거하지 않았다. 계산은 공통 정규화 단정도 좌표에서 수행한 뒤 프로젝트 길이 단위로 복원한다.

| 시작 조건 | 엄격 표면 RMS | 0.001 표면 RMS | 엄격 95백분위 | 0.001 95백분위 |
|---|---:|---:|---:|---:|
| 정렬 상태 | 1.483794452 | 1.483797612 | 3.627864176 | 3.627965844 |
| 틀어진 상태 | 1.483794412 | 1.483802865 | 3.627861959 | 3.627865071 |
| 역할 반전 | 1.483794452 | 1.483797612 | 3.627864176 | 3.627965844 |

정렬 상태의 전체 RMS 변화는 +0.000213%, 틀어진 상태는 +0.000570%다. 양방향 각각의 RMS·95백분위도 검사했으며 최대 악화는 한 방향 95백분위의 **+0.02643%**였다. 전체와 양방향 각각에 적용한 기존 5% 허용 조건을 모든 후보가 통과했다. 이전 CCCoreLib 결과와의 같은 기준도 모두 통과했다.

정렬 상태의 평균/중앙/최대 표면 거리는 엄격 설정 0.731432/0.246260/8.364269, 완화 설정 0.731366/0.246246/8.364338이었다. 따라서 모든 오차 지표가 좋아졌다고 해석하지 않는다. 엄격 결과와의 자세 회전 차이는 정렬 상태 약 0.000329°, 틀어진 상태 약 0.000726°였다.

이 결론은 지정한 두 메시와 세 초기 조건에 대한 것이다. 지난 보고서의 조밀한 점군–성긴 메시 모서리 접평면 편향은 이번 변경의 해결 대상이 아니며, 해당 한계를 해결했다고 판정하지 않았다.
