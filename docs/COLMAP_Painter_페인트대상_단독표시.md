# Painter 페인트 대상 단독 표시

- 작성일: 2026-10-06.
- 범위: 페인팅 모드 진입·종료 시 현재 페인트 대상 외 오브젝트의 표시.

## 동작과 구현

기존 진입은 현재 데이터셋의 점군·카메라 축과 뷰포트 보조 윤곽만 숨겼다. 연결된 실제 프로젝트에서 기본 Cube·Light·모델 축 오브젝트가 숨겨지지 않는 상태를 확인했다.

실제 페인트 뷰 레이어에 포함된 다른 메시·조명·빈 오브젝트·일반 카메라를 `hide_set`으로 숨긴다. 전역 `hide_viewport`와 렌더 표시를 변경하지 않는다. 페인트 대상은 유지한다. 현재 카메라와 현재 데이터셋의 관리 카메라는 배경 사진과 프레임 전환에 필요하므로 오브젝트 자체를 숨기지 않고 기존 페인트 뷰포트의 보조 윤곽 숨김을 유지한다.

원래 숨김값은 오브젝트 `PointerProperty` 참조와 뷰 레이어 식별자로 저장한다. 이름 변경·삭제·같은 이름의 새 오브젝트·파일 저장 및 재로드에서 다른 오브젝트를 잘못 변경하지 않는다. 사용자·다른 도구 오브젝트에 소유권 태그를 추가하지 않는다. 반복 준비는 최초 기록을 덮어쓰지 않는다.

종료·진입 실패 때 자신이 적용한 숨김만 복구한다. 원래 숨긴 오브젝트는 계속 숨기며 페인트 중 사용자가 직접 다시 표시한 오브젝트는 덮어쓰지 않는다. 일반 작업공간의 뷰 레이어와 이전 점군·카메라 복구 기록을 보존한다. 기존 레이어·이미지·카메라 연결·원근투영 복귀를 변경하지 않는다.

API 근거: [Blender 오브젝트 뷰 레이어 표시 API](https://docs.blender.org/api/current/bpy.types.Object.html).

## 검증 기준

1. 대상만 표면으로 표시하고 배경용 카메라와 사진을 유지한다.
2. 종료 시 기존 숨김·다른 뷰 레이어·사용자 변경을 보존한다.
3. 이름 변경·삭제 후 같은 이름 생성·저장 및 재로드에서 실제 참조로 복구한다.
4. 실제 페인팅 모드 진입·종료·재진입과 배경·원근투영 복귀를 검증한다.
5. 최상위 설치 ZIP을 갱신하고 현재 Blender에 적용한다. 사용자 프로젝트는 저장하지 않는다.
