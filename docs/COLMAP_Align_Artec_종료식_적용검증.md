# Artec 상대 변화 종료식 적용 검증

2026-10-21 · `codex/artec-align-engine` · `point-kd-icp-v2`

**확인된 Artec 종료식으로 교체했다. 같은 두 메시에서 갱신은 3→2회, 틀어진 상태에서는 6→5회로 줄었다. 전체 시간 중앙값은 0.7~3.2% 감소했고, 독립 표면 RMS 증가는 최대 0.000973%였다. 새 정책의 준비 실행을 포함한 18회 모두 수렴·PASS이며 REVIEW 사유는 없었다.**

## 변경한 종료 판정

[바이너리·실행 검증으로 확인한 식](COLMAP_Align_Artec_종료식_분석.md)을 다음과 같이 적용했다.

```text
ε = 1e-9
τ = double(float32(0.001)) = 0.0010000000474974513

dE = abs(E_k - E_(k-1)) / (E_(k-1) + ε)
dt = norm(t_k - t_(k-1)) / (norm(t_(k-1)) + ε)
dr = norm(r_k - r_(k-1)) / (norm(r_(k-1)) + ε)

수렴 = dE < τ 또는 (dr < τ 그리고 dt < τ)
```

- `E`는 갱신 뒤 대응을 다시 검색한 목적함수 RMS다. 메시 대상에서는 접평면 잔차, 점군끼리는 유클리드 거리다.
- `t`, `r`은 **한 번의 갱신**의 이동 벡터와 회전축×라디안각이다. 누적 최종 행렬이나 중심 이동량/대각선이 아니다.
- 처음 이동·회전 이력은 영벡터다. 오차 조건이 먼저 만족하면 즉시 종료하고 변환 이력은 갱신하지 않는다.
- 비교는 엄격한 `<`다. 이전의 전후 대응 수 일치 조건과 별도의 영 오차 수렴 우회 조건을 제거했다.
- 30회 상한은 수렴 검사보다 우선한다. 명시적인 사용자 지정 허용치는 그대로 지원한다.
- 결과에 종료 정책·실제 허용치·분모 상수·종료 분기·갱신 행렬을 남긴다. 평가하지 않은 이동·회전 상대 변화는 `null`이다. 기존 중심 이동량·회전각 항목은 관찰용으로 유지한다.

종료식의 의미가 달라져 알고리즘 버전을 `point-kd-icp-v1 → point-kd-icp-v2`, 네이티브 엔진 버전을 `1.0.0 → 1.1.0`으로 변경했다. 작업 파일 프로토콜은 그대로다.

이번 범위는 **수렴 판정 교체**다. 전체 유효점, KD 검색, 31스레드, 법선·반경·5% 제외 정책, 배정도 좌표·잔차 계산은 유지한다. 고정 대응에서 목적함수가 악화되는 갱신의 거부와 대응 수가 절반 이하로 급감할 때의 검토 분기도 유지한다. Artec의 단정도 잔차 곱이나 최저 오차 후보 선택까지 복제한 것은 아니며, 기존처럼 마지막 승인 후보를 반환한다.

## 비교 방법

작은 메시 188,400점·357,749면과 큰 메시 10,173,478점·20,128,488면, 합계 **20,486,237면**을 사용했다. 사용자 `test.align.blend`를 별도 Blender 5.2.0 LTS 백그라운드 프로세스에 복원했다. 사용자 장면과 OBJ를 저장·수정하거나 열린 Blender의 설치본을 교체하지 않았다.

새 ZIP의 Python 경로에서 공개 기본 Align 경로와 보존한 이전 0.001 네이티브 실행 파일을 번갈아 호출했다. 이전 파일은 실제 세 조건 동시 충족·대응 수 일치 정책을 그대로 실행한다. 비교 실험에서만 경로를 지정하며 제품에 이전 종료식을 추가하지 않았다. 비교용 이전 작업에도 조정기 버전 v2가 기록되므로 실제 계산기는 각 결과의 네이티브 SHA-256과 정책으로 구별한다.

각 초기 조건에서 정책별 준비 실행 1회 후 순서를 교차하며 정책별 5회, 총 36회 실행했다. 준비 실행은 시간 통계에서 제외했다. 시작부터 미리보기 수신까지의 입력 준비·해시·외부 계산·결과 검증 시간을 측정하며 프로젝트 복원과 화면 그리기는 제외한다. 측정 중 다른 빌드나 성능 실험을 병행하지 않았다.

이전 실행 파일의 해시와 최종 행렬은 [직전 0.001 검증](COLMAP_Align_수렴기준_001_재검증.md)과 정확히 일치했다. 각 정책·조건의 준비 실행 및 5회 측정에서도 최종 행렬이 반복마다 정확히 같았다.

## 속도와 검토 상태

| 초기 조건 | 이전 0.001 중앙값 | 새 종료식 중앙값 | 시간 감소 | 갱신 횟수 | 새 결과 |
|---|---:|---:|---:|---|---|
| 정렬된 상태 | 4.066초 | **4.039초** | 0.67% | 3 → **2** | 수렴·PASS |
| Z축 0.5°·이동 (0.6, −0.4, 0.2) 추가 | 4.260초 | **4.223초** | 0.88% | 6 → **5** | 수렴·PASS |
| 기준 A·이동 P 역할 반전 | 4.167초 | **4.035초** | 3.16% | 3 → **2** | 수렴·PASS |

시간 범위는 정렬 상태에서 이전 4.051~4.107초, 새 정책 3.975~4.181초였다. 틀어진 상태는 4.246~4.303초와 4.162~4.410초, 역할 반전은 4.093~4.370초와 3.974~4.432초였다. **범위가 겹치므로 소폭의 중앙값 감소를 안정적인 성능 향상으로 일반화하지 않는다.** 한 회 덜 반복한다는 결과는 모든 실행에서 재현됐다.

두 정책 모두 이번 36회에서 네이티브 `SUCCESS / CONVERGED`, 상위 품질 `PASS`, 검토 사유 없음이었다. REVIEW를 강제로 숨기지 않았다. 직전 허용치 완화에서 이미 사라진 REVIEW가 이번에도 다시 나타나지 않은 것이다.

이번 자료에서 한 회 먼저 끝나는 직접적인 이유는 **대응 수 일치 조건의 제거**다.

| 초기 조건 | 새 종료 시점 | 상대 오차 변화 | 전후 대응 수 | 실제 종료 분기 |
|---|---:|---:|---|---|
| 정렬·역할 반전 | 2회 | 0.0002667093984 | 174,001 → 174,006 | 오차 조건 충족 |
| 틀어진 상태 | 5회 | 0.0004147037901 | 174,004 → 174,005 | 오차 조건 충족 |

이 시점은 이전 이동량·회전각 조건도 통과하지만 대응 수가 달라 이전 정책에서는 계속 실행했다. 새 식은 오차 조건만으로 종료한다. 이동·회전 상대 변화 분기는 실제 Artec 합성 호출 사례와 별도 네이티브 시험으로 검증했다.

정렬 상태에서 KD 구성 중앙값은 이전 1.970초, 새 1.984초다. 검색 합계는 0.130→0.095초, 먼 대응 제외는 0.073→0.060초로 감소했다. 큰 대상 트리 구성·입력 적재·법선·Python 준비 비용이 유지되므로 반복 한 회 감소가 전체 시간을 크게 줄이지 않는다.

## 독립 표면 정확도

이전 검증과 동일한 양방향 표면 표본과 고정 겹침 마스크, 총 **59,187개 평가점**을 사용했다. 표본·마스크 SHA-256도 일치한다. 각 후보마다 평가점을 바꾸지 않았다. 정렬 엔진의 접평면 목적함수와 별도로 삼각형 BVH의 최근접 표면 거리를 평가했다. 평가 계산기는 공통 정규화 단정도 좌표를 사용하며 결과는 프로젝트 세계 길이 단위로 복원한다. 물리 단위를 확인하지 않았으므로 mm로 표기하지 않는다.

| 초기 조건 | 이전 표면 RMS | 새 표면 RMS | RMS 증가율 | 이전 95백분위 | 새 95백분위 |
|---|---:|---:|---:|---:|---:|
| 정렬·역할 반전 | 1.483797612 | 1.483801632 | **0.000271%** | 3.627965844 | 3.628341075 |
| 틀어진 상태 | 1.483802865 | 1.483817299 | **0.000973%** | 3.627865071 | 3.627343778 |

전체와 각 방향의 RMS·95백분위를 따로 검사했다. 새 정책 18개 후보 모두 이전 0.001 대비 5% 악화 제한을 통과했다. 가장 큰 개별 지표 증가는 반대 방향 95백분위의 **0.012299%**였다. 과거 CC 결과 대비 기준도 모든 후보가 통과했다. 이는 이 두 메시의 표면 비교 결과이며 정답 자세에 대한 절대 정확도 보증은 아니다.

기존 성긴 메시·밀도 차이 자료의 정점 접평면 근사 한계는 이번 변경으로 해결하지 않았다. 전체 엔진의 적용 범위는 [1차 구현 검증의 제한](COLMAP_Align_Artec_방식_엔진교체_구현검증.md)을 계속 따른다.

## Artec 기록과의 관계

과거 Artec의 이미 정렬된 상태 단일 계측은 전체 5.319초, ICP 2.831초, 갱신 1회였다. 이번 새 경로는 전체 중앙값 4.039초, 갱신 2회다. 서로 다른 계측 범위·실행 시각·입력 내부 표현·대응 및 잔차 계산을 가지므로 Artec 대비 성능 우위를 확정하는 비교로 사용하지 않는다. **종료식이 같아도 대응점·잔차가 다르면 종료 횟수는 같지 않다.**

## 검증과 산출물

- 실제 Artec 종료 함수에서 확인한 합성 입력 10건을 네이티브 종료 함수 시험에 이식했다. 오차 단독 통과, 변환 두 조건, 한쪽만 통과, 영 분모, 큰 절대 이동의 작은 상대 변화가 모두 일치한다.
- 엄격한 `<` 경계, 영 이력, 오차 단락 평가, 반대 축 회전, 회전 부호를 추가 검사했다.
- 실제 네이티브 23개 검사 통과: 알려진 강체 정답, 큰 좌표, 스레드 재현성, 변경된 대응 수에서도 오차 조건으로 종료, 반복 상한 우선, 취소·실패·원본 보존 포함.
- 작업 계약 9개, Blender 연동 6개, 빌드 회귀 314개 및 격리 설치 검증 통과. 기존 알려진 변환의 정확도 허용치는 완화하지 않았다.
- 측정된 모든 새 반복의 오차 변화 식·기본 허용치·분모 상수·오차 종료 분기를 다시 계산해 확인했다. 사용자 원본 파일의 크기·수정 시각과 형상 출처 해시는 보존됐다.
