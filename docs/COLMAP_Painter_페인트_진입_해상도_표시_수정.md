# Painter 페인트 진입 색상·참고 표시·기본 해상도 수정

- 작성일: 2026-10-06
- 범위: 페인트 진입·종료 상태, COLMAP 참고 표시, 기존 원본 해상도 판정.
- 기존 입력 구조 변경과 도구 표시 수정은 보존한다. 정렬·Modifier·페인팅 알고리즘은 변경하지 않는다.

## 재현과 원인

연결된 사용자 프로젝트를 변경하지 않고 재진입 해상도 검사 함수를 실행했다. `Use Base Resolution`은 켜져 있고 원본 사진과 기존 페인트 이미지 모두 8192×8192인데, 검사는 비활성 해상도 선택값인 2048×2048을 적용할 대상으로 반환해 전체 레이어 초기화 오류를 냈다.

현행 Original 레이어는 외부 원본 이미지를 직접 참조한다. 외부 이미지를 수정하지 않으므로 과거의 `pp_is_original_layer` 이미지 태그가 없다. 재진입 검사는 이 과거 이미지 태그와 Mix 연결만 조회해 원본을 찾지 못하고 UI 해상도로 돌아갔다. Scene에 보존된 `original_source_image` 권위를 조회해야 한다.

기존 진입 색상 초기화는 명시적 스텐실 브러시 재연결에만 있었다. 일반 페인트 진입은 사용자 색상을 유지했다. 기존 참고 표시 숨김은 점군만 처리했으며, 작업공간 전환 전 View Layer에서 적용했다. COLMAP 카메라와 실제 페인트 View Layer의 참고 표시를 함께 처리해야 한다.

## 변경 계획

1. 페인트 진입 완료 시 Texture Paint의 통합 색상을 활성화하고 흰색으로 설정한다. 읽기 전용 브러시 자산은 수정하거나 교체하지 않는다. 진입 후 사용자의 색상 변경은 유지한다.
2. 실제 페인트 View Layer에서 현재 Painter 데이터셋이 소유한 점군·카메라 축 표시만 숨긴다. 카메라는 전체 숨김 대신 페인트 뷰포트의 보조 윤곽 표시를 끈다. 카메라 배경·데이터·타임라인·이미지 연결은 유지한다. 이전 숨김값과 보조 윤곽 설정을 기록해 종료·실패 시 복구하고, 이전 카메라·점군 복구 기록도 호환 처리한다.
3. 원본 해상도 판정은 같은 대상·관리 재질의 현행 Original Source를 우선 조회한다. 이전 자료는 기존 Mix 조회를 유지한다. 옵션을 끈 명시적 해상도 변경은 기존 레이어 초기화 확인을 계속 요구한다.
4. 외부 원본 파일을 사용하는 재진입 회귀로 먼저 오류를 재현하고 수정 후 재사용·원본 불변·옵션 해제 시 경고 유지 여부를 확인한다. 실제 화면에서 진입·종료·재진입과 색상·참고 표시를 확인한다.
5. 정식 ZIP을 저장소 최상위에 갱신하고 설치본을 교체한다. 사용 중인 프로젝트의 레이어·이미지를 초기화하거나 저장하지 않는다.

## 카메라 배경 표시 회귀 수정

연결된 사용자 프로젝트에서 Background 토글, 현재 프레임의 이미지 연결, 불투명도 1.0과 Camera View는 모두 정상인데 배경 사진이 보이지 않았다. 앞선 참고 표시 숨김에서 카메라 오브젝트 전체를 `hide_set(True)`로 처리했기 때문이다. 현재 카메라의 숨김만 잠시 해제했을 때 배경 사진이 표시되는 것을 실제 뷰포트에서 확인했고, 진단 뒤 원래 상태로 복구했다.

카메라 전체 숨김을 제거하고 페인트 뷰포트의 `overlay.show_extras`만 끈다. 이 옵션은 카메라·빈 오브젝트·조명의 보조 윤곽 표시를 함께 제어하며 배경 이미지 표시는 유지한다. 다른 작업공간의 표시 설정과 카메라의 사용자 숨김은 변경하지 않는다. 종료 시 자신이 적용한 보조 윤곽 설정만 원복한다. 이전 설치본이 저장한 카메라 숨김 복구 기록도 계속 처리한다.

Blender는 카메라 윤곽과 배경 이미지 표시를 별도 경로로 처리한다. 확인한 공식 구현: [카메라 표시 코드](https://github.com/blender/blender/blob/main/source/blender/draw/engines/overlay/overlay_camera.hh).
